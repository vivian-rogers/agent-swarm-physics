\hmodel{Models 01 (Curie--Weiss) and 09 (Hawkes). The spin $s_i(t)=\pm1$ marks agent $i$ active in minute $t$. $h_i(b)$ is a per-agent field per 30-min block. The stall indicator $z(t)$ is a second field that switches agents off: operator off, not yet started or finished, consolidating, or infrastructure error. $\pi$ is the stall fraction and $p$ the on-rate. The order parameter is the gain $g$. The stall-adjusted gain trims to the window in which all agents run and sets scaffold-unavailable agent-minutes to the block mean. Block-shift surrogates, drawn on the kept rows, give the null.}

\hmath{\vspace{-8pt}\begin{gather*}
P(\mathbf s)\propto\exp\!\Big[\tfrac{\beta J_0}{2N}M^2+\textstyle\sum_i\big(h_i(b)+\Delta_i z(t)\big)s_i\Big],\quad M=\sum_i s_i\\
\mathrm{VR}=\frac{\sum_b n_b\operatorname{Var}_b M}{\sum_b n_b\sum_i\operatorname{Var}_b s_i},\qquad g=1-\mathrm{VR}^{-1}\\

f=1-\frac{g_{\rm adj}-\langle g_{\rm adj}\rangle_{\rm null}}{g_{\rm raw}-\langle g_{\rm raw}\rangle_{\rm null}}
\end{gather*}\vspace{-10pt}}

\htelos{An always-on swarm with a daily start and stop shows synchrony that is mostly its own runner schedule. This holds for mean-field coupling, the market-mode eigenvalue and co-activation. Agents boot and stop together whether or not the operator announces it. Before you draw surrogates, trim each day to the window in which all agents run. Here that removes about 80\% of regime-III co-activation. Real excess remains only where agents co-move (\#44, \#51). Do not alert on joint silences as a stall signal: error logs do not predict them, and provider outages leave no trace. Message-driven swarms (regime I) gain nothing from this rule.}
