\htelos{A useful negative plus one practical rule, now sharper. If you run an always-on swarm with a daily start and stop, any synchrony number (mean-field coupling, market-mode eigenvalue, co-activation) is mostly your own runner schedule: agents boot and stop together whether or not you announce it. Trim each day to the window in which all agents run \emph{before} drawing surrogates; here that removes about 80\% of regime-III co-activation and leaves real excess only where agents genuinely co-move (\#44, \#51). Joint silences are not a stall signal worth alerting on, error logs don't predict them, and provider outages leave no trace. Message-driven swarms (regime I) get nothing from this.}

\hbottom{Joint silences are rare and operator-scheduled, not platform stalls; in the always-on regime 70--80\% of apparent co-activation is the runner starting and stopping everyone together, so trim to the common running window before measuring synchrony.}
