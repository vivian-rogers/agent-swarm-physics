\hwhat{HH376 says that an agent changes project only at its own model call, by a Glauber update whose odds for project $b$ rise with the read messages that name the agent and link $b$; unnamed links add nothing, and without reads the switch rate is constant per call, not per hour. H133 labels every call with a project (shared \texttt{project\_calls}: 2.6\,M calls, 61,939 non-reserved hops) and fits a conditional logit with project $\times$ active-hour effects in 41 non-reserved units. \textbf{The coupling test is untestable as planned}: named reads about a non-current project are so rare that a planted $\gamma_\mathrm{nam}=1$ gives under 2 such hops per unit (power $\approx 0$; Amendment A1). \textbf{The clock test holds in regime II/III}: background switches do not scale with wall time ($\eta_\mathrm{sw}=-0.02\,[-0.07,+0.02]$, 24 units). The reserved periods are not run.}

\hmodel{Models 10 (kinetic Potts) and 02 (asynchronous updates). At call $c$ agent $i$ on project $a$ stays or moves to an active project $b$ with heat-bath odds $e^{u_b}/(e^{u_\mathrm{stay}}+\sum_{b'}e^{u_{b'}})$. Reads enter $u_b$ as $\ln(1+N)$ counts of named, unnamed and named-but-in-flight messages linking $b$. A project-wide attention burst (H28) would raise all three counts together; a wall clock would make background hops grow with the call's span.}

\hmath{\vspace{-6pt}\begin{gather*}
u_\mathrm{stay}=\alpha_i+\phi\ln(1+d)\\

\end{gather*}\vspace{-8pt}}

\htelos{For an operator: an agent's spontaneous project switching is a per-call rate, so slowing its call rate slows its drift between projects, and long pauses do not add switches. Descriptively, a message that names an agent and links a project goes with about 2.8 times the expected switches onto that project. A link the agent reads without being named goes with none. To move an agent, name it in the message with the link. This rule is not yet a tested result.}

\hbottom{In regime II/III an agent's background project-switch hazard runs on its own call clock (switch-span elasticity $-0.02\,[-0.07,+0.02]$, 24 units). Named-read coupling is untestable at the planted effect; post hoc, hops onto a project named to the agent are 2.8$\times$ expected, unnamed 0.93$\times$, in flight 1.1$\times$.}
