\hwhat{H25's equal-time talk dial measures feedback within one minute. Coupling acts at the recipient's next model call, so HH262 asked whether a dial built on that read-out call shows larger gains that are still subcritical. The test covers 66 non-holdout units in 35 periods, with 1.47M receiving calls in all-present windows. The read-out loop gain $g_{lag}$ counts the extra talk messages that one message causes through reading. Every unit is subcritical (all upper bounds $<0.40$). The gain is 0.13 in regime III (median) and $\approx 0$ in regimes I and II. It exceeds the equal-time dial in only 7/35 periods, so \textbf{the HH claim fails}. In regime III, messages that name the recipient carry about half of the gain. $g_{lag}$ ranks periods like H42's read-out Hawkes fit ($\rho=0.55$). The holdout is not run.}

\hmodel{Linear response on the call clock (models 01, 09). Agent $i$'s call $c$ is a talk call ($Y_{ic}=1$) or not. $R^m_{ic}$ counts peer messages read at $c$ that were posted within the call's latency $d_c$ before its start. $P_{ic}$ counts messages posted within $d_c$ after the start (in flight, unreadable). $a_{i,d,\kappa}$ is an agent $\times$ day $\times$ call-class field. $\bar r$ is the readers per message and $\bar m$ the messages per talk call.}

\hmath{\vspace{-6pt}\begin{gather*}
P(Y_{ic}{=}1)=a_{i,d,\kappa}+\beta_m R^m_{ic}+\beta_o R^o_{ic}+\beta_P P_{ic}+\gamma\cdot E_{ic}+\rho\,Y_{i,c-1}\\
J_1^*=\beta_m-\beta_P,\qquad g_{lag}=\bar m\,\bar r\,J_1^*,\qquad T/T_c=1/g_{lag}\\
g_{eq}=1-\Big[\textstyle\sum_t\sum_i X_{it}^2\Big]\Big/\textstyle\sum_t\big(\sum_i X_{it}\big)^2
\end{gather*}\vspace{-8pt}}

Regime-I periods sit on $g_{lag}\approx0$ while $g_{eq}$ reads 0.05--0.40: a fast shared field, not read-out coupling. Regime-III periods lie near the diagonal at 0.07--0.23.}

\htelos{For a monitor: report $g_{lag}$, not the equal-time dial, as distance to a talk cascade. The equal-time dial counts shared fields as feedback, and in regime I that is all it sees. Here one talk message causes about 0.13 further messages through reading (amplification $\times1.15$, $T/T_c\approx8$). The gain stays flat as the swarm grows from 21 to 32 agents, because per-read coupling falls with headcount ($\rho=-0.59$). For an operator: naming carries the coupling. A named message raises the recipient's next-call talk probability by 0.08; an unnamed one by 0.004. No village configuration came near runaway, so this is a gauge, not a lever.}

\hbottom{Read-out talk coupling is real but small and subcritical ($g_{lag}\approx0.13$ in regime III, $\approx0$ elsewhere), it is carried by named messages, and the equal-time dial overstates it wherever fields drive talk.}
