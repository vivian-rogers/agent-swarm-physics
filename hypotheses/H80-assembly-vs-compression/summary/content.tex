\hwhat{H80 tests assembly theory's index against compression as a signature of script work. The units are 16-commit windows labelled automated or agent (DQ4) in G51, G31 and G41. A fourth unit, G51+post, adds 28 scripts that commit after the village's last day. The index is a Re-Pair grammar bound, checked against an exact search. Adding the index to compression changes AUC by $-0.007$ to $+0.001$, so the kill ($\ge0.05$) is far. Timing alone, the scheduler baseline, reaches 0.92--1.00. Compression reaches 0.96 only for single cron streams that replay identical commits. Across the 28 scripts it falls to 0.25. High-index, high-copy command motifs belong to single agents. Only 7.8\% appear on a joiner's first day across $\ge2$ labs, so P5 fails. Holdout script frozen, not run.}

\hmodel{Model 04 used as a tool family. A window is a token string $x$ of length $L=16$; one token hashes one commit's size fields. The assembly index $a(x)$ is the fewest joins that build $x$ with reuse. It equals the minimal grammar size minus the basis (Abrahão Cor.~8), and Re-Pair bounds it from above. The rivals are entropy rate, LZ76, LZ78, gzip and zstd (C), and the timing features (T). Motifs are 4--8-grams of command heads; $n_i$ is the number of sessions holding motif $i$.}

\hmath{\vspace{-5pt}\begin{gather*}
a(x)=\min_{D}\sum_{d\in D\cup\{x\}}\big(\mathrm{tiles}(d\,|\,D_{<d})-1\big)\ \le\ a_{\rm RP}=|\mathcal R|+|x_{\rm RP}|-1\\
A=\sum_i e^{a_i}(n_i-1)/N_T,\qquad \mathrm{NCD}(x,y)=\frac{C(xy)-\min(C_x,C_y)}{\max(C_x,C_y)}\\
\Delta\mathrm{AUC}_A=\mathrm{AUC}(\mathrm{C}+a_{\rm RP})-\mathrm{AUC}(\mathrm{C})
\end{gather*}\vspace{-7pt}}

\htelos{A monitor that must flag script commits under an agent's identity should use timing: off-hours activity, regular gaps, and no agent turn nearby. Timing alone gives AUC $\ge0.91$ here. Compression catches only replay loops. A script that writes varied content looks like an agent, and the compression detector then flags 97\% of a script-free period. The assembly index adds nothing to compression, so drop it. For a selection meter, high index $\times$ high copy here measures one agent repeating its own habit. That habit is present from the agent's first day, even in isolation. No operator decision changes because of assembly theory; the timing rule is the usable part.}

\hbottom{The assembly index is compression in disguise here, compression detects replay rather than automation, and the scheduler's timing carries the agent-vs-script label.}
