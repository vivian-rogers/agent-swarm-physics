\hmodel{Two-variable kinetic Ising model (02) with Hawkes kernels (09). Each agent has a visible spin $n_i$ (active per minute) and a hidden field $c_i$: the room messages that arrived since its last model call. Calls start on the scaffold's schedule (context assembled at $t_{\rm call}$). At each call the field is read and reset, and couplings $J_{ij}$ act only then. $W$: read-out delay; $o$: call offset (1 = the receiving call); $\beta_F$: coupling change after a forced erasure.}

\hmath{\vspace{-5pt}\begin{gather*}
c_i(t)=\{m:\ \mathrm{room}(m)=r_i,\ t_{\rm call}^{-}\le t_m< t\}\\
P(a_i\mid \text{call } k)\propto \exp\big[a\,\big(h_i+\textstyle\sum_{m\in c_i(t_{{\rm call},k})}J_{i,\mathrm{src}(m)}\big)\big]\\
G(\tau)=\textstyle\sum_w p(w)\,\Delta R(\tau-w)\\
D=G(o{=}1)-G(o{=}0)
\end{gather*}\vspace{-7pt}}

\htelos{An agent cannot react until a model call has the message in its context, so the swarm's coupling delay is its call cadence: about 15 s to context assembly when busy, minutes when paused. That follows from the scaffold, so the news is modest; the value is quantitative and diagnostic. A nudge acts at the target's next call, not minutes later, so its lag is the target's pause schedule. Compaction cuts about a fifth of conversational coupling. Newcomers couple only to what they have been shown. And exposure can silently come loose from the room (the replay bug), so log what each agent was actually shown. The response kernel is a brief transient at read-out, not a step.}

\hbottom{On the context ledger, every response we can measure (addressing, replies, nudged activity, newcomers' first contacts) starts at the first model call whose context contains the message, and erasing that context cuts the coupling by about a fifth.}
