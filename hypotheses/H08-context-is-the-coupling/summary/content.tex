\hwhat{The question is whether agents couple only through what enters their model calls. Round 1b re-runs 17 non-holdout goal periods on the context ledger, which records which call received which message, with reply labels. (1) A recipient's chance of addressing the sender jumps at the call that received the message, not at the call already running. This holds in 14/17 periods (round 1: 11/17) and in 17/17 on reply labels. Regime I now passes in 4/6 periods: its round-1 failure came from the call-start rule. (2) A nudge's activity response starts at the target's receiving call (median read-out 108 s). Dropped events and H04's isolation rule made round 1's extra 3-min lag. (3) A forced erasure (NE41) cuts reply coupling to senders read before it by 21\% (8/9 periods; predicted 30\%). (4) Newcomers name an old-timer only after they receive its message (NE32, 35/35 pairs). (5) The Claude Code agent's feed replays April 2025 from 2026-03-17. The holdout has not run.}

\hmodel{Model 02 (two-variable kinetic Ising) with Hawkes kernels (model 09). Each agent has a visible spin $n_i$ (active per minute) and a hidden field $c_i$: the room messages that arrive after its last model call. Calls start on the scaffold's schedule, and the scaffold assembles the context at $t_{\rm call}$. Each call reads and resets the field, and the couplings $J_{ij}$ act only then. $W$ is the read-out delay. $o$ is the call offset (1 = the receiving call). $\beta_F$ is the coupling change after a forced erasure.}

\hmath{\vspace{-5pt}\begin{gather*}
c_i(t)=\{m:\ \mathrm{room}(m)=r_i,\ t_{\rm call}^{-}\le t_m< t\}\\
P(a_i\mid \text{call } k)\propto \exp\big[a\,\big(h_i+\textstyle\sum_{m\in c_i(t_{{\rm call},k})}J_{i,\mathrm{src}(m)}\big)\big]\\
G(\tau)=\textstyle\sum_w p(w)\,\Delta R(\tau-w)\\
D=G(o{=}1)-G(o{=}0)
\end{gather*}\vspace{-7pt}}

\htelos{The coupling delay equals the call cadence. A message cannot change an agent before a model call has the message in its context. The delay is about 15 s when the agent is busy and minutes when it pauses. To make a message act fast, send it before the target's next call. A forced erasure cuts conversational coupling by 21 $\pm$ 7\%. Newcomers couple only to what the scaffold shows them. Log what each call received: exposure can detach from the room (the replay bug). The response kernel is a brief transient at read-out, not a step.}

\hbottom{Every measured response starts at the first model call whose context holds the message; erasure of that context cuts the coupling by about a fifth.}
