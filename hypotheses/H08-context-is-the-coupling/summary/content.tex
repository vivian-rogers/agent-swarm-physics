\hwhat{The question is whether agents couple only through what enters their model calls. Rounds 1b and 2 use the context ledger, which records which call received which message, on 17 non-reserved goal periods. (1) A recipient's chance of naming or replying to the sender jumps at the call that received the message, not at the call already running: names 14/17 periods, replies 17/17; other-room messages give no jump (8/8). (2) Content follows only inside those replies. At equal lag, a statement from a call that read the message is closer to it than an in-flight statement only when it names or replies to the sender (G51: +1.25 vs $-$0.39 cos$\times$100 without them; 0/9 regime-III periods positive without names). Without names, in-flight talk is closer: both answer the same earlier turn. (3) A forced erasure (NE41) cuts reply coupling by 21\%. Senders written into memory get 5.5 pp more replies, but whether that protects the thread is unpowered. (4) The Claude Code agent's event feed replayed 2025 for 9 days (17 active hours) while its status stayed current. A five-fetch event-age monitor catches it in 0.4 active hours. Nothing is confirmed on reserved data.}

\hmodel{Model 02 (two-variable kinetic Ising) with Hawkes kernels (model 09). Each agent has a visible spin $n_i$ (active per minute) and a hidden field $c_i$: the room messages that arrive after its last model call. Calls start on the scaffold's schedule, and the scaffold assembles the context at $t_{\rm call}$. Each call reads and resets the field, and the couplings $J_{ij}$ act only then. $W$ is the read-out delay. $o$ is the call offset (1 = the receiving call). $\beta_F$ is the coupling change after a forced erasure.}

\hmath{\vspace{-5pt}\begin{gather*}
c_i(t)=\{m:\ \mathrm{room}(m)=r_i,\ t_{\rm call}^{-}\le t_m< t\}\\

G(\tau)=\textstyle\sum_w p(w)\,\Delta R(\tau-w)\\
D=G(o{=}1)-G(o{=}0)
\end{gather*}\vspace{-7pt}}

\htelos{The coupling delay equals the call cadence. A message cannot change an agent before a model call has the message in its context: about 15 s when the agent is busy, minutes when it pauses. Name the recipient if you want its content to move: unaddressed messages shift content no more than co-response does. A forced erasure cuts conversational coupling by 21 $\pm$ 7\%; writing the sender into memory is not shown to restore it. Log what each call received and alarm when the median age of fetched events over five fetches exceeds 1 h: that caught the replay in 0.4 active hours with no false alarm. A content-only monitor does not.}

\hbottom{Responses start at the first model call whose context holds the message, and content moves only inside the replies that name the sender; erasure cuts the coupling by about a fifth.}
