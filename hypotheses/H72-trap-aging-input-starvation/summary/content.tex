\hwhat{The claim: an idle agent's escape slows with trap age only because no new input has reached it. A wake is a call after an idle call; there the agent acts or idles again. Round 1 refuted the claim in-sample: the age slope survives every starvation clock (G51 $-0.48\to-0.53$), and recent input \emph{lowers} escape. Round 2 asks which input or context variable carries the aging, on the same 20{,}237 G51 wakes, scored on held-out days. Directed-input starvation explains none of it ($\varepsilon=-0.01$). Undirected chatter explains 22\%. The context's self-share (H16's own-call urn) explains 65\% [59, 71], against $\le22\%$ in synthetic worlds where aging is intrinsic or frailty. Its coefficient is the urn's $+1$ (1.09), and its slope transfers from G51 to G38. Chatter adds a small, separate hold ($\beta_C=-0.085$) that a directed read cancels. The reserved data are not used.}

\hmodel{Model 09 (exogenous input events) and model 02 (kinetic escape) with an urn on the context. At wake $g$ the agent acts (a run of $\ge3$ active calls) or idles. Clocks: trap age $a$ and wake index $k$. Three mechanisms compete on one base (agent effects, pause, time of day, others' activity, reads at the wake, reset step, trap kind at start). S: minutes since the last directed read. C: undirected items read at the 5 calls before the wake. F: own idle calls as a share of own calls in the context segment. Traps that start with a consolidation are dropped.}

\htelos{To judge how stuck an idle agent is, count its own re-pauses in the current context, not the minutes since someone wrote to it. A context full of its own pauses is the trap, and erasing it frees the agent (H16: 0.47 to 0.84 at the next wake). Quiet does not deepen the trap, and chatter does not break it. In \#51, 48 undirected messages over five calls cut the next-wake escape odds by about a quarter, unless one message names the agent. The urn coefficient is portable: a monitor fitted on one period predicts another.}

\hbottom{Trap aging is carried by the context's self-share, not by missing input; room chatter adds a weak hold that a mention cancels.}
