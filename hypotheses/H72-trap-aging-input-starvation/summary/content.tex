\hwhat{The claim: an idle agent's escape slows with trap age only because it has not read new input for a long time. Each call after an idle call is a gate, where the agent acts or idles again. Two clocks run at every gate: trap age $a$ since the last sustained run, and starvation $s$ since the last call that read a novel chat item (DQ1 ledger). A logit hazard with agent fixed effects holds both clocks; 18 goal periods with $\ge 200$ gates; natives NE43, blocked spells and the \#focus room. \textbf{The claim fails.} In all four periods that age with power, the age slope survives the control (G51: $-0.48 \to -0.53$). The starvation slope has the opposite sign: recent input lowers escape (G51 $+0.23$ [$+0.11$, $+0.33$]). The holdout is not run.}

\hmodel{Discrete-time escape hazard on the call clock (model 09: exogenous input events; model 02: kinetic escape from the idle state). The state is idle or active per call. Current reads at the gate (directed, undirected, nudge, bookend) are kicks. Nuisance terms: declared pause, time of day, others' activity, last run length. Rivals: intrinsic aging (R1), two clocks (R2), kicks only (R3), a common room field (R4).}

\mathrm{logit}\,P(\mathrm{esc}_g)=\alpha_i+\beta_a\ln a_g+\beta_s\ln s_g+\gamma\!\cdot\!c_g+\delta\!\cdot\!z_g\\
\text{H72: }\beta_a=0,\ \beta_s<0;\qquad \rho=1-\beta_a/\beta_{a0}\\
b_{\rm impl}=\beta_s\,\kappa,\quad \kappa=\partial\ln s/\partial\ln a\ (\text{within agent})
\end{gather*}\vspace{-7pt}}

\htelos{Do not treat an aged idle agent as starved of input. Feeding it room chatter will not wake it: undirected input read in the last minutes lowers its escape odds by about 20\% per $e$-fold of recency in \#51. Kicks act only at the call that reads them. Trap depth is a property of the trap, about $a^{-0.5}$ in the odds, and it does not reset when input arrives. An operator should address the agent directly at a gate (H16, H60) and not count on ambient traffic. A scaffold builder who wants fewer deep traps should cap the trap, for example with a forced re-plan after $k$ re-pauses, and should not add more messages. Blocked (stuck-on-task) spells behave the same way: they age by themselves whatever the input.}

\hbottom{Trap aging is intrinsic: the age clock survives every input-starvation control, and recent undirected input holds idle agents idle rather than freeing them.}
