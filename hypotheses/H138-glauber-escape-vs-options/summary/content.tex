\hwhat{HH381 says that an agent working on one project leaves it the way a Glauber spin leaves its Potts state: at each of its own calls, the chance of leaving grows in proportion to the number of other open options, $h\propto(q-1)e^{-\beta\Delta}$. H138 builds one row per agent, 30-min window and project visit (work: DQ4 host labels; attention: strict project mentions) and fits the leave hazard per own call against the number of projects other agents held in the last 2 active hours. \textbf{Leaving does not rise with the open options}: the pooled option elasticity is $-0.66\,[-1.64,0.32]$ in the work channel (13 units) and $-0.28\,[-0.42,-0.15]$ in the attention channel (31 units). The literal law $\varepsilon_q=1$ is rejected. The card's kill ($\varepsilon_q=0$ vs 0.5) is unpowered in the work channel (0.43), so the verdict by its rule is inconclusive.}

\hmodel{Models 10 (kinetic Potts) and 02 (single-spin kinetics). Heat-bath walker on the agent's call clock: from project $a$ it moves to $b$ with probability $\nu e^{u_b}/(e^{u_a}+\sum_{b'}e^{u_{b'}})$. For rare leaves $h\approx\nu e^{-u_a}Z_\mathrm{alt}$; with equal attractions $Z_\mathrm{alt}=(q-1)e^{u}$, so $\varepsilon_q=\partial\ln h/\partial\ln(q-1)=1$ at a fixed stay field. Rival R-finish: the agent leaves when its task ends, $\varepsilon_q\approx0$.}

\htelos{For an operator: opening more parallel projects does not make agents drop their current one faster. Expect about 0.06--0.3 leaves per 100 own calls in the work channel whatever the number of open projects; in own-role weeks agents leave slightly less when many projects are live. Plan churn from task length, not from the size of the menu. Whether naming a target project pulls agents is open (a small attention signal, below the label-noise level).}

\hbottom{Within goal periods the per-call leave hazard does not grow with the number of open projects (pooled elasticity $-0.66\,[-1.64,0.32]$ work, $-0.28\,[-0.42,-0.15]$ attention), so the Glauber law $\varepsilon_q=1$ is rejected; the HH381 kill itself is unpowered.}
