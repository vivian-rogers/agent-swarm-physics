\hwhat{The test asks whether a herding wave's size is set by how many uncommitted agents read the seeding link within one model-call cycle. A seed is the first chat link to a project: 928 seeds in 23 non-holdout periods. The context ledger gives the read-out timing. Synthetic swarms validate the design. \emph{Seeding holds:} adoptions jump about 20-fold at the first link and stay in the poster's room (other-room ratio 0.12). They almost never happen without the link in context (1.5\%). \emph{The clock fails:} prompt readers adopt no more often than later readers ($\mathrm{RR}_{\rm timely}=1.06$ [0.93, 1.22], 726 adoptions). The receptive count adds nothing to held-out wave-size prediction. The project's current share is the only predictor (AUC 0.72 against 0.46). Poster status adds nothing. Deadline-bound calls are the exception: in the \#26 runoff, ballots equal readers inside the 100-s window (8 = 8). The holdout is not run.}

\hmodel{Kinetic Potts with read-out-gated updates (model 10) and the field-versus-imitation test of model 03. The state $\sigma_i$ is a project or none; it switches only at $i$'s model calls. A seed (first chat link to project $X$) is a field pulse at $i$'s reading call, at message age $a_i$. $A_X$: attractiveness; $u_i$: uncommitted; $c_i$: call cycle; $g$: decreasing gate; $k_X$: current adopters. $R$ is the receptive count. Rivals: poster status, a shared field, room size $N$, current share.}

\hmath{\vspace{-5pt}\begin{gather*}
P(\sigma_i\!\to\! X\,|\,a_i)=1-\exp\!\big[-A_X u_i\, g(a_i/c_i)\, e^{\beta J k_X/(N-1)}\big]\\
\mathbb{E}[S]\approx A_X\big[p_{\rm hi}R+p_{\rm lo}(N_{\rm sus}-R)\big],\ \ R=\#\{i: u_i\!=\!1,\,a_i\!\le\! c_i\}\\
\log\mathbb{E}[y_{is}]=\alpha_s+\delta\,\mathbf{1}[a_i\!\le\! c_i]+\gamma u_i+\ldots,\ \ \mathrm{RR}_{\rm timely}=e^{\delta}
\end{gather*}\vspace{-7pt}}

\htelos{Do not time project announcements to the agents' call loops: posting when many agents are about to read buys about 9\%. Three things move a pile-on. Without a link, almost no wave forms. Agents already on the project raise the wave. Readers in the live conversation adopt 3$\times$ more. For deadline-bound calls (votes, polls, sign-ups) the clock binds: the wave equals the agents whose next call lands inside the window. In regime III, keep such windows at $\ge$15 min. A 2-min window misses about a third of the swarm; 15 min reaches about 90\%. This rule rests on one election.}

\hbottom{Announcements seed herding waves and rooms bound them; the project's current share, not the call clock, sets wave size, except for deadline-bound calls.}
