\hwhat{HH342 proposed a parameter-free check of the read-out loop gain. For a linear point process with branching ratio $g$, collective count variance at long windows exceeds the independent-agent value by $1/(1-g)^2$. H111 compares this sum rule, with H67's $g_{\rm lag}$, against the collective Fano ratio $\Phi$ of 10-min talk counts in 66 non-holdout units (35 periods). In regime III the rule closes: the pooled ratio $r_F=\Phi/\Phi_{\rm pred}$ is 1.01 [0.94, 1.09] over 18 units, with no between-unit spread, and $\Phi-1$ tracks $g_{\rm lag}$ ($\rho$ 0.60). No unit reaches the kill ($r_F\ge2$). In regime I, where $g_{\rm lag}\approx0$, talk co-varies $1.34\times$ [1.18, 1.52] more than the loop allows. The holdout is not run.}

\hmodel{Linear multivariate Hawkes process on the call clock (model 09) with a fluctuation decomposition (model 14). Each agent has private talk noise of any form (clocked calls, own bursts). Reading couples agents through a cross-response matrix $K$ with eigenvalue $g$ on each room's collective mode. $n_i$ is agent $i$'s talk count in a window, $\Phi$ the ratio of collective to summed private variance, $N$ the present agents, $n_b$ the room sizes. $\Phi$ divides out every private noise level.}

\hmath{\vspace{-6pt}\begin{gather*}
C(T)/T\to(I-K)^{-1}\Sigma\,(I-K)^{-\top},\qquad \Phi(T)=\frac{\mathrm{Var}\sum_i n_i}{\sum_i\mathrm{Var}\,n_i}\\
\Phi_{\rm pred}(g)=\frac{N(1-g)^{-2}}{\sum_b\big[(1-g)^{-2}+\frac{n_b-1}{(1+g/(n_b-1))^{2}}\big]}\approx\frac{1}{(1-g)^2}\\
r_F=\Phi(10\,{\rm min})\,/\,\Phi_{\rm pred}(g_{\rm lag})
\end{gather*}\vspace{-8pt}}

\htelos{For an operator, H67's read-out gain is the whole story of collective talk clustering in the current scaffold: a push is amplified by $1/(1-g)\approx1.15$ and the swarm's talk variance by $1/(1-g)^2\approx1.32$, with nothing left over for a hidden field at 10--30 min. A monitor can use $\Phi$ on 10-min talk counts as a cheap, label-free check of the coupling gauge: $\Phi$ above $1/(1-g_{\rm lag})^2$ by more than $\sim0.3$ flags a field or a coupling the read-out estimator misses. In regime-I-style scheduled chat, expect that excess ($\Phi\approx1.3$ with $g_{\rm lag}\approx0$).}

\hbottom{In regime III, talk obeys a fluctuation--response sum rule with no free parameter: the collective Fano ratio equals $1/(1-g_{\rm lag})^2$ to within 9\% (pooled over 18 units), so the read-out loop accounts for all collective talk variance.}
