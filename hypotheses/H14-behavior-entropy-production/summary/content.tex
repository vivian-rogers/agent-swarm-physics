\hmodel{Kinetic Potts (models 02, 10). $x_i(t)\in\{1..q\}$ is agent $i$'s behavior state per turn (single agent) or per 1-min bin (swarm). $P_{ab}$ and $\pi_a$ are its transition matrix and occupancies. $\Sigma_i$ is the entropy production per transition: the pair KL, a lower bound for non-Markov agents. It is estimated with the Aguilera--Ito--Kolchinsky dual on antisymmetrized transition indicators $g_{ab}$, cross-fitted by day (Newton step $\hat\Sigma_N$). $J_{ij}^{ab}$ are cross-agent couplings, $\Delta\Sigma$ is the collective increase of the bound, and $A_{abc}$ a cycle affinity.}

\hmath{\vspace{-5pt}\footnotesize\setlength{\jot}{1pt}
\begin{gather*}
\Sigma_i=\textstyle\sum_{a,b}\pi_aP_{ab}\ln\dfrac{\pi_aP_{ab}}{\pi_bP_{ba}},\qquad g_{ab}=\mathbf{1}[a\!\to\!b]-\mathbf{1}[b\!\to\!a]\\
\Sigma_g=\max_\theta\big[\theta\cdot\langle g\rangle-\ln\langle e^{-\theta\cdot g}\rangle\big],\qquad \hat\Sigma_N=2\,\big\langle \bar g_a^{\top}K^{-1}\bar g_b\big\rangle_{a\neq b}\\
P(x_i'=a\,|\,\mathbf{x})\propto e^{\,h_i^a+\sum_j J_{ij}^{a,x_j}},\qquad \Delta\Sigma=\Sigma_{1+2}-\Sigma_1\\
A_{abc}=\ln\dfrac{P_{ab}P_{bc}P_{ca}}{P_{ac}P_{cb}P_{ba}}
\end{gather*}\vspace{-7pt}}

\htelos{Mostly a careful measurement of the harness, now with one agent-level residue. The coarse arrow and the regime-I/III contrast are scaffold structure (sessions, consolidation). What survives removing the scaffold is fine tool workflow (e.g.\ read $\to$ edit $\to$ commit), irreversible in every agent; it is a per-agent fingerprint, not a steering handle. Semantic irreversibility is real but small and does not track output or progress, so EP is not a ``useful work'' meter. Practical lessons: use a calibrated detailed-balance or block-flip null, null-subtract before comparing agents, and never apply a reset burn-in on coarse windows (it manufactures arrows). An operator would change nothing.}

\hbottom{Every agent's fine tool workflow is irreversible even with the scaffold removed, but the coarse arrow and the regime contrast are scaffold structure, and no family, collective or ``useful-work'' arrow appears.}

\hcaveats{Soft-label observables attenuate EP roughly by the square of label accuracy, so per-agent v3 tests are nearly blind and only pooled tests are primary. A reset burn-in on 5-min windows was pre-registered and turned out to be a selection artifact (resets start activity bursts); it is reported as invalid. Newton blows up for a few strongly asymmetric agents (one G40 value 16.5), which drives the fragile Anthropic $>$ OpenAI result. NE14 has one pre-change day; NE43 windows are 5 days. Non-Markov agents make all values lower bounds.}
