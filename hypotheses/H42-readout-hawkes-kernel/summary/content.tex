\hwhat{H42 refits H03's multivariate Hawkes model with kernels anchored at the recipient's next model call (the read-out call). Round 1 (71 non-reserved units, 35 periods): talk locks to each agent's \emph{own} call clock (+1.1 nats per held-out message, 57/57 units), and an ordinary read barely changes whether an agent talks ($n_{\rm cross}\approx0.004$ vs 0.061 for H03's kernel). Round 2 asks how reading acts. Call starts are mechanical (chains, timers, the chat schedule), so a read can act only through what the reading call does. In regime III a named read raises talk at that call by 0.076 per read. Half of this, 0.046, comes with no exchange in progress. The call clock moves only through this switch to talk. Under a fitted Cox field, H03's exponential term mostly vanishes (survival 0.22), while the named kernel keeps 0.90.}

\hmodel{Two layers: the call skeleton (start times and classes) and the mark of each call. Agent $i$'s call $c$ starts at $t_c$; $w_c$ is the smaller of its latency, the previous gap and 120 s. $R^m_{X}$ counts messages of class $X$ (cold named, thread named, unnamed) read at $c$ and posted in $(t_c-w_c,t_c)$. $P_X$ counts those posted in $(t_c,t_c+w_c)$, in flight. $O_c$ is an outcome decided by call $c$: talk, timer pause, log gap to the next call, class of the next call. $a_{i,d,\kappa}$ is an agent $\times$ day $\times$ class cell. R3 replaces round 1's shared shape $s_b$ with a free log-rate $\phi$ per day (and room) $\times$ 10-min bin.}

\hmath{\vspace{-5pt}\begin{gather*}
O_c=a_{i,d,\kappa}+\textstyle\sum_X\big[\beta^m_XR^m_{X,c}+\beta^P_XP_{X,c}\big]+\gamma\cdot E_c+\rho\,Y_{c-1}\\
J_{O,X}=\beta^m_X-\beta^P_X\quad(\text{minus the call-skeleton null})\\
\lambda^{B}_i=f_i\big(t-c_{k^*}\big)\Big[c_{id\kappa}\,e^{\phi_{d,r,b}}+\Phi^{\rm self}_i+\textstyle\sum_b \frac{w_b}{M_b}N_b(k^*)\Big]
\end{gather*}\vspace{-7pt}}

\htelos{Model each agent's call schedule and call class before you fit an influence model to agent logs. Then judge cross terms against a fitted common field, not shift surrogates. H03's exponential cross-triggering mostly disappears under such a field. To get a response, name the agent. In the always-on regime a named message adds 0.076 talk at the reader's next call, 0.046 even outside an ongoing exchange; an unnamed one adds 0.004. A message cannot start a call. It changes only what the next call does, so naming makes an agent speak sooner (about 3\% shorter gap), not wake earlier.}

\hbottom{Reading changes what the next call does, not when it comes: a named read raises talk at the read-out call by 0.076 [0.066, 0.086] (half of it outside any exchange), and this named kernel survives a fitted Cox field while H03's exponential cross term does not.}

\hcaveats{The log-gap effect is fragile: a pooled synthetic field world gave 0.011, just above its 0.01 tolerance. With the mark held fixed it is not resolved, but that check conditions on a mediator (post hoc). The pause effect is underpowered. A 10-min Cox field absorbs about 25\% of planted read-out excitation, so field survival understates real coupling. Thread status rests on DQ2 parents and recent naming, so some cold messages may sit in exchanges DQ2 missed. Regime-I log gap and unnamed session start fail the call-length world and are not read.}
