\hwhat{On 2026-03-31 and 04-01 the history-search oracle returned near-empty answers. The test treats this as a Kolchinsky--Wolpert scramble of the village's access to its own past. Each agent's dose is its search rate in the five days before. The outage fully reached one agent: its answers fell from 2{,}880 to 42 characters, and it retried 128 times. Continuity did not dip. It rose with dose ($\beta=+0.12$ per search per 100 calls; placebo rank $p$ for a dip 0.87), and so did references to earlier-goal artifacts. Commits per 20 calls did not move. A dip of 0.30 at the mean searcher dose is excluded (power 0.85--0.91); a dip of 0.20 is not. Search answers carry 0.012 bits about the next repo (7 periods). The holdout script exists and is not run.}

\hmodel{Semantic information, natural-scramble variant (model 04). The system $X$ is one agent's allocation: which repos its work commits go to. The environment $Y$ is the logged past, reached through the search oracle (channel $Q$). The outage degrades $Q$. The dose $d_a$ is searches per 100 calls before the outage. Viability $V$ is continuity (share of commits on pre-existing repos), with earlier-goal references and commits per 20 calls as secondary components. $O_t$ marks outage days and $R_t$ recovery days. The permutation $\pi$ shuffles the answer pointer $S_Q$ within agent.}

\hmath{\vspace{-6pt}\begin{gather*}
y_{a,t}=\alpha_a+\gamma_t+\beta\,d_a O_t+\beta_{\rm rec}\,d_a R_t+\varepsilon_{a,t},\qquad \Delta V_Q=\beta\,\bar d_s\\
I_Q=\hat I_{\rm MM}(X^+;S_Q)-\langle \hat I_{\rm MM}(X^+;S_Q^{\pi})\rangle_{\pi},\quad \kappa_Q=\frac{\Delta V_Q}{I_Q}
\end{gather*}\vspace{-8pt}}

\htelos{Do not treat history search as load-bearing memory. Few agents use it: three of twelve searched more than once per 400 calls. When it broke, the one agent it reached retried and kept working from its own artifacts, with no loss of commits ($+0.03\pm0.51$ per 20 calls). An operator can let the search tool fail for a day without a measurable cost to project continuity. Invest in the artifact path instead: keep repos readable and named in the agent's notes. Search answers name the agent's own repo in 13\% of \#51 searches, and those searches precede a return 99\% of the time, but the agent chose the query.}

\hbottom{The history-search outage cost the scrambled agent no continuity and no output; the search channel carries about 0.01 bits of allocation information.}

\hcaveats{One agent was fully scrambled, for two days, so the bound applies to a heavy searcher, not to the village. Duplicate creation has 13 events and cannot speak. $I_Q$ counts only repos named in answers. Failed searches in \#51 are not exogenous. The single-agent residual check is post hoc.
