\hwhat{Agent slots carry a project label per 30-min window: a cluster of the agent's self-written goal, the repo it links, or (round 1b) the repo it commits to. Exact finite-$N$ simulations with the real label gaps fit neutral cooperative dynamics (NCD), Hubbell drift and a herding rival to 9 statistics. \textbf{NCD failed} in free weeks (4/5 failed, 1 mixed), and in rounds 1 and 1b all three models are rejected on stated goals in every free week (joint check $p<0.01$): 72--91\% of goal clusters are held by one agent. Round 1b (second embedding model, style removed) leaves this intact, but a control week whose project is known (\#35, one fork per room) shows stated goals just as fragmented while work sits 96--100\% on the room's fork: goal clusters measure sub-tasks, not projects. Work labels concentrate on shared repos where one exists; there Hubbell-like copying can fit (\#30), without NCD's signature. Copying follows reading: a project named in a message the agent has read predicts a switch (OR 8.6 vs unread).}

\hmodel{Model 06 (Pi\~nero et al.\ 2025). $N$ individuals (agent slots), each holding one species (project). Per step, with probability $\mu$ a new project replaces a random slot $C$. Otherwise $C$ copies slot $A$'s project only if $A$ and a third slot $B$ hold different projects: cooperation, so rare projects recruit more per capita. $\lambda=\sum_i x_i^2$ is the Simpson index of shares $x_i=n_i/N$. Rivals: Hubbell (always copy) and herding (copy favoured when $A,B$ agree).}

\hmath{\vspace{-8pt}\begin{gather*}
b_n=(1-\mu)\tfrac nN\big(1-\tfrac nN\big)^2,\qquad
P_n\propto\frac{(1-\mu)^n}{n}\,e^{-(n-N\lambda^*)^2/2N}\\
\tfrac1\mu=\sqrt{\tfrac{\pi N}{2}}\,\mathrm{erfcx}\!\Big(\sqrt{\tfrac N2}\,(\mu-\lambda^*)\Big),\quad
\mu_B=\tfrac{e^{-2}}{\sqrt{2\pi N}},\ \ \mu_L=\sqrt{\tfrac{2}{\pi N}}\\
P(\text{recruit to } i)\propto x_i\,e^{\beta x_i}:\ \ \beta<0\ \text{NCD},\ 0\ \text{Hubbell},\ >0\ \text{herding}
\end{gather*}\vspace{-10pt}}

\htelos{Neutral cooperative dynamics doesn't apply to these swarms. What agents \emph{say} they are doing is a spread of private sub-tasks in every week, so stated-goal abundances are a poor project census. What they \emph{work} on concentrates on a shared repo when the task offers one, and spreads out when the task hands each agent its own artifact or role (\#44 free room, \#51), as H11 found for effort. There, neutral copying is a fair description; there is no cooperator core. The copying that exists runs through reading, so an operator who wants a shared project must assign or announce it. Diagnostics: work-label singleton fraction and copy-consistency.}

\hbottom{Free LLM agents state private sub-tasks but work on shared repos when one exists; no cooperative (NCD) dynamics, neutral copying at best, and copying follows what agents read.}
