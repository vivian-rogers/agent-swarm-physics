\hwhat{H113 measures how much content an agent takes up from a batch of $k$ peer messages read before it speaks. Each row is a talk call: the reader's next statement, orthogonalized to its previous statement and the goal, is regressed on the summed batch vectors with a gain $\gamma_1 k^{-b}$. HH345 predicted total uptake $\propto k^{0.34}$; the coordinator later corrected H18's value to $k^{0.50}$. On \#51 timer-wake batches, where others set $k$, $a_U=1-b=0.31$ [0.25, 0.37]. Pooled over the 6 periods identified against a topic field, talk calls give 0.23 [0.16, 0.31]: the pre-set kill (0.34 excluded) is met, and 0.50 is excluded everywhere. The holdout is not run.}

\hmodel{Models 04 and 12: a linear read-out channel into the destination's next statement, with an in-flight placebo source. $x_m$: DQ5 \texttt{style\_resid32} vector of batch message $m$; $y$: the reader's statement; $P$ removes the reader's previous statement and the goal directions. $\gamma(k)$ is the per-message uptake slope, $U(k)=k\gamma(k)$ the total uptake per call. $b=0$: no bottleneck; $b=0.66$: HH345; $b=1$: one message per call.}

\hmath{\vspace{-5pt}\begin{gather*}
Py=\gamma_1k^{-b}\sum_{m\in B}Px_m+\gamma_F\sum_{m\in F}Px_m+\epsilon,\qquad U(k)=k\gamma(k)\propto k^{a_U},\ a_U=1-b\\
I(k)=-\tfrac{D}{2}\log_2\!\big(1-R^2_{\rm cv}(k)\big),\qquad a_I\approx1-2b+r\ \ (\text{low SNR})
\end{gather*}\vspace{-7pt}}

\htelos{Reading more messages before speaking helps, but with steep diminishing returns: ten messages buy about twice the content of one. An operator who wants an agent to act on a specific message should send it alone or make it the newest; burying it in a batch of ten dilutes it about fivefold. The bottleneck is per call, so faster call cadence, not longer batches, raises throughput.}
