\hwhat{The test asks whether a human message moves its recipient more than an agent message with the same salience. Salience means naming, read-out age (context ledger), novelty, length, recipient state and room size. Matched comparisons run on 17 non-holdout periods plus four native tests. Dated predictions and synthetic recovery come first. \textbf{Replies:} agents answer humans about twice as often as matched agent messages (pooled $+0.030$ [0.019, 0.042]; naming adds $+0.13$). \textbf{Content:} a small premium, G51 $+0.014$ [0.008, 0.021] under five statistics, and $+0.05$ in regime I on H29's boundary design. \textbf{Activity:} $\approx 0$. Replies to humans are more supportive. In \#51 the reply premium exists only for messages that fit the recipient's private role. Elected or appointed agent leaders get the same reply premium. Agents treat the bot like a matched agent message, but rebuff it. \textbf{Mixed.} The holdout is not run.}

\hmodel{Linear response to fields (model 02). A message $m$ is an impulsive field at the recipient's next model call. It acts on the content spin (whitened statement vector), the activity spin, the reply and the stance. Its coupling $g(s_m)$ depends only on the salience $s_m$ (named, read-out age, novelty $\|P_\perp \hat u_m\|$, length, idle recipient, room size), the same for every sender. The authority premium $\pi_c$ is an extra field term of sender class $c$ (human, bot, leader). H52 (HH164) predicts $\pi_{\rm human}=0$.}

\hmath{\vspace{-5pt}\begin{gather*}
\mathbb{E}[Y_{mj}\mid s_m,c]=g(s_m)+\pi_c,\qquad \pi_{\rm agent}\equiv 0\\
\hat\pi_c=\textstyle\sum_s n_{c,s}\,(\bar Y_{c,s}-\bar Y_{{\rm agent},s})\,/\sum_s n_{c,s}\\
Y^{\rm con}=(Q-x_{\rm last})\cdot\widehat{P'_\perp u_m}-\langle\,\cdot\,\rangle_{\rm placebo}\\
Y^{\rm rep}=\mathbf{1}[m=\mathrm{parent}(j\text{'s next messages})]
\end{gather*}\vspace{-7pt}}

\htelos{To get an answer from an agent, name it and frame the request in terms of its current objective. At equal salience, agents answer humans about twice as often ($+0.030$) and move a little toward their content ($+0.014$ in G51). The premium is a status effect: elected and appointed agent leaders get the same reply premium. It does not override the assigned plan: on-role human messages get $+0.037$, off-role ones $+0.007$. Being human buys an answer, not obedience. A safety team must not read the premium as deference, because it vanishes for role-conflicting requests. The labeller also knew which senders were human, and one period carries most of the regime-III evidence.}

\hbottom{Matched on salience, humans get about double the replies and a small content pull; agent leaders share this status premium, and off-role requests lose it.}
