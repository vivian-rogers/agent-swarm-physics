\hwhat{On 03-16 the village split into \#best (3 agents) and \#rest (10), and each room took its own copy of the RPG all twelve had built in \#34. Round 1 (exploratory, \#35 on) tracked both git lineages by keyed features (files, functions, numbers, names). Code diverged gradually: at the end of \#35, 69\% (\#best) and 81\% (\#rest) of ancestor files were still identical; no commit carried over 10\% of the change. Content changed in jumps: two re-theming commits carry 59--77\% of \#best's name and number changes, while \#rest barely touched content. Copying dominates: $I_{\rm transform}\approx0.01\,I_{\rm copy}$. Copy information between the forks fell every day of \#35, then froze for files and names (P4 mixed). The independent-lineage bound held exactly. The 3 shared innovations were convergent bug fixes, not leakage. Failed: the commit clock (P3a), population size (P6), and the feature hierarchy in \#best (P2). The \#34 holdout test has not run.}

\hmodel{Copying vs.\ transformation (model 08) plus a mutation clock. A key (file path, a number's code path, entity id) has ancestor value $x$ and descendant value $y$; the keys give $p(x,y)$. Vertical channel: ancestor $\to$ fork after clock time $\tau$ (active hours, commits or file-touches); horizontal: \#best $\leftrightarrow$ \#rest. $q_x=p(Y{=}x|X{=}x)$; $d$: binary KL divergence (bits). $c$: copy fraction; $\kappa$: chance-corrected. $\mu$: per-key mutation hazard; $f$: mutable fraction.}

\hmath{\vspace{-5pt}\footnotesize\setlength{\jot}{1pt}
\begin{gather*}
I(X;Y)=I_{\rm copy}+I_{\rm transform},\qquad I_{\rm transform}\ge0\\
I_{\rm copy}=\textstyle\sum_x p(x)\,d\big(q_x\,\|\,p_Y(x)\big)\,\mathbb{I}\big[q_x>p_Y(x)\big]\\
c=P(Y{=}X),\qquad \kappa=\dfrac{c-\sum_x p_X(x)p_Y(x)}{1-\sum_x p_X(x)p_Y(x)}\\
c(\tau)=(1-f)+f\,e^{-\mu\tau}\\
P(y_{\rm best}{=}y_{\rm rest}\mid\text{ancestor key})=P(\text{both unchanged})
\end{gather*}\vspace{-7pt}}

\htelos{Mostly a curiosity, honestly. This is one natural experiment with $n=2$ forks. Its main facts need no information theory: forks drift while teams edit them and stop when they stop, and content changes when a team decides to re-theme. Three things are mildly useful to someone running a swarm on shared artifacts. (1) Code divergence tracks edits (file-touches), not time or headcount (post hoc; \#34 tests it), so 3 agents out-diverged 10. (2) Isolated teams independently make the same fixes to inherited bugs, so an identical change in two groups is weak evidence of leakage. That is a real caution for anyone auditing information flow between sandboxed agents. (3) Per-feature copy fractions are a cheap lineage diagnostic. None of this is a lever.}

\hbottom{The RPG forks diverge measurably, code gradually per edit and content in team-chosen jumps, by copying rather than transformation and with no detectable leakage; but $n=2$, and the holdout test has not run.}
