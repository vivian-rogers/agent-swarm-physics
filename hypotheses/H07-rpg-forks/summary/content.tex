\hwhat{On 03-16 the village splits into \#best (3 agents) and \#rest (10), and each room takes its own copy of the \#34 RPG. Round 1 (\#35 on) tracks both git lineages by keyed features: files, functions, numbers and names. Code diverges gradually: at the end of \#35, 69\% (\#best) and 81\% (\#rest) of ancestor files are still identical. No commit carries over 10\% of the change. Content changes in jumps: two re-theming commits carry 59--77\% of \#best's name and number changes. Copying dominates: $I_{\rm transform}\approx0.01\,I_{\rm copy}$. Copy information between the forks falls every day of \#35, then freezes for files and names (P4 mixed). The independent-lineage bound holds exactly. The 3 shared innovations are convergent bug fixes, not leakage. The commit clock, population size and \#best's feature hierarchy fail. Round 1b changes no verdict: cross-team reads are 2\% of \#35 chat, and none names a shared innovation. The \#34 holdout test has not run.}

\hmodel{Model 08 (copying vs.\ transformation) plus a mutation clock. A key (a file path, a number's code path, an entity id) has ancestor value $x$ and descendant value $y$. The keys give $p(x,y)$. The vertical channel runs from ancestor to fork after clock time $\tau$ (active hours, commits or file-touches). The horizontal channel runs between \#best and \#rest. $q_x=p(Y{=}x|X{=}x)$, and $d$ is the binary KL divergence in bits. $c$ is the copy fraction and $\kappa$ its chance-corrected form. $\mu$ is the per-key mutation hazard, and $f$ is the mutable fraction.}

\hmath{\vspace{-5pt}\footnotesize\setlength{\jot}{1pt}
\begin{gather*}
I(X;Y)=I_{\rm copy}+I_{\rm transform},\qquad I_{\rm transform}\ge0\\
I_{\rm copy}=\textstyle\sum_x p(x)\,d\big(q_x\,\|\,p_Y(x)\big)\,\mathbb{I}\big[q_x>p_Y(x)\big]\\
c=P(Y{=}X),\qquad \kappa=\dfrac{c-\sum_x p_X(x)p_Y(x)}{1-\sum_x p_X(x)p_Y(x)}\\
c(\tau)=(1-f)+f\,e^{-\mu\tau}\\
P(y_{\rm best}{=}y_{\rm rest}\mid\text{ancestor key})=P(\text{both unchanged})
\end{gather*}\vspace{-7pt}}

\htelos{This is mostly a curiosity: one natural experiment, $n=2$ forks. Forks drift while teams edit them and stop when the edits stop. Code divergence tracks edits, not time or headcount: 3 agents out-diverge 10 (post hoc; \#34 tests it). Isolated teams make the same fixes to inherited bugs: all 3 shared innovations here are convergent. An auditor of sandboxed agents should treat an identical change in two groups as weak evidence of leakage. Per-feature copy fractions are a cheap lineage diagnostic. None of this is a lever.}

\hbottom{The RPG forks diverge by copying (code per edit, content in one agent's jumps) with no readable leakage; a fork family with a shared upstream re-converges.}
