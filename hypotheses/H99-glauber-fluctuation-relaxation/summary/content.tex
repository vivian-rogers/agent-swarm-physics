\hwhat{Mean-field Glauber dynamics ties two numbers together: the gain $g$ read from equal-time fluctuations must also set how much slower the collective mode relaxes than one agent. HH81 asked whether this holds without inferring $J$. The test covers 70 non-holdout units in 35 periods, on talk, activity (control) and content. Talk minutes carry no single-agent memory ($\rho_\perp(1)\approx0.006$), so a post hoc statistic, the collective memory excess $\Delta\rho_1$, replaced the planned log-ratio. \textbf{Where talk coupling is real (regime III), the collective outlives the prediction} in every resolved period: $\Delta\rho_1=+0.067\,[0.034,0.100]$ in \#51. Regime I passes, but the test has no power there. Content is a field. Kicks outlive the fluctuation clock: the \#51 nudge response is $\times9.5$ the Onsager value. The holdout is not run.}

\hmodel{Models 02 and 01. Spin $s_i(t)$: agent $i$ talks (or acts) in minute $t$, centred within 30-min blocks on the all-present window; content uses 32-d style-residualized window vectors. $M_t$ is the collective (uniform) mode, $X^\perp_t$ the transverse modes. Linearized mean-field Glauber relaxes $M$ at rate $(1-g)/\tau_0$ and $X^\perp$ at $1/\tau_0$, with the same $g=\beta J_0(1-m^2)$ that sets the equal-time variance ratio.}

\hmath{\vspace{-6pt}\begin{gather*}
\tau_0\dot m=-m+\tanh\!\big(\beta(J_0m+h)\big)\;\Rightarrow\;\tau_c=\tau_0/(1-g)\\
g_\chi=1-\textstyle\sum_t p_t\big/\sum_t c_t,\quad c_t=M_t^2,\ p_t=\big(|X_t|^2-M_t^2\big)/(N-1)\\
\Delta g=\Big[1-\frac{\ln\rho_c(1)}{\ln\rho_\perp(1)}\Big]-g_\chi,\qquad \Delta\rho_k=\rho_c(k)-\rho_\perp(k)^{\,1-g_\chi}
\end{gather*}\vspace{-8pt}}

\htelos{For a monitor: the equal-time talk dial is not a distance to criticality in regime III. There the collective talk mode keeps memory for minutes ($\Delta\rho_1\approx0.07$) that no agent has on its own, which is what a coupling delayed by one read-out call produces. Use a lagged estimator (H67's $g_{lag}$) and report $\Delta\rho_1$ beside the dial as a check. For an operator: a nudge's effect does not decay like spontaneous activity. Expect about ten times more response, spread over 10--30 min, than the agent's own one-minute clock predicts, and do not read the kick kernel as a susceptibility. In regime I nothing here distinguishes a coupling from a fast shared field.}

\hbottom{Equal-time fluctuations do not predict the swarm's relaxation where talk coupling is real: the collective mode outlives the mean-field Glauber prediction (delayed read-out coupling or a slow conversation field), kicks outlive it tenfold, and content behaves as a field.}
