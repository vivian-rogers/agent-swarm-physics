\hwhat{A daily change-point monitor runs on all 282 non-holdout active days, from April 2025 to September 2026. It has five channels: log record schemas (S), synchronous within-agent behavior shifts (M), search-answer format (O), drive and schedule counters (D) and content topic shift (C). The fused alarm is the maximum channel score at $\tau=4$. It is scored against 211 catalogued changes and 6 undocumented ones. On documented tool changes the fused score has AUC 0.68 [0.54, 0.82] (random-date $p$ 0.059): \textbf{mixed}. It alarms on 18\% of placebo days, against a predicted 10\%. The schema channel has no false alarms and dates platform changes to the day, naming the changed fields. It also finds six provider API format changes that no catalog lists. Drive counters date both NE43 steps. Topic shift remains the goal detector. The holdout is not run.}

\hmodel{Models 02 and 11. A day $d$ is one step of a driven system. A platform step changes the rules for every agent at once, so the record schema changes or every agent's own behavior shifts together. An operator step changes the drive counters. A goal step is a field step on content. Each feature is scored by a robust trailing $z$ against the previous $B=10$ days. $c_k$ is the Gaussian consistency factor of the trimmed SD. $n^{\rm new}_d$ and $n^{\rm retired}_d$ count platform-wide record signatures (field names and value types) that appear or retire on day $d$.}

\hmath{\vspace{-6pt}\begin{gather*}
z(d)=\big[x(d)-\mathrm{med}_B\,x\big]\big/\max\{\mathrm{sd}^{\rm trim}_B(x)/c_k,\ \mathrm{floor}\}\\
z_M(d)=\max_f\big|\mathrm{med}_i\,z_{i,f}(d)\big|,\qquad z_S(d)=4\,\big(n^{\rm new}_d+n^{\rm retired}_d\big)\\
Z(d)=\max\{z_S,z_M,z_O,z_D,z_C\},\qquad \text{alarm if } Z(d)\ge\tau=4
\end{gather*}\vspace{-8pt}}

\htelos{Run a schema diff on your logs. Hash the field names and value types of every record each day, and alarm when a signature used by $\ge2$ agents appears or retires. Here it gave 0 false alarms in 34 quiet days. It dated the regime change, the outreach tool and an undocumented search-tool rename to the day, and it found six silent provider API changes. Add plain counters for operator drives (bookends, nudges, hours, joint silence): they dated both NE43 steps. Use topic shift for goal changes (AUC 0.89). Do not fuse heavy-tailed behavior statistics with a Gaussian threshold: they fire on 6--9\% of quiet days each. Prompt-only changes stay invisible to every channel.}

\hbottom{A schema diff plus operator counters is a precise, nearly free platform-change monitor; the fused five-channel alarm is too noisy as tuned.}

The evaluation catalog is H56's CHANGELOG parse. The holdout is not run.}
