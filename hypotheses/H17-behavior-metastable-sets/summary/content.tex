\hwhat{Is agent behavior a Markov state model (MSM) with a few slow metastable sets? Is its slowest timescale $t_2^*$ a per-period order parameter, longest in stuck periods? Round 1 fits MSMs on 6 action classes per active minute in 27 non-holdout periods. The Chapman--Kolmogorov (CK) test fails in 27/27. $t_2^*$ (5--24 min) beats a sojourn null by a small margin and does not track errors. Regime III is slower than regime I. Verdicts: 13 mixed, 14 failed. Round 1b repeats the fit on Jev v3.1 behavior states (soft vectors, a noise-cancelling estimator) and counts real failures instead of stderr. The semantic slowest mode lasts hours (agent-day scale). The slow set is still acting vs waiting. Higher $p_{\rm blocked}$ goes with \emph{shorter} $t_2^*$. The native tests (forced erasures, nudger switch-off, \#27's spontaneous shift) fail. The holdout is not run.}

\hmodel{Kinetic Potts chain out of equilibrium (models 10, 02). The state $x_t\in\{$browse, type, shell, chat, idle, consolidate$\}$ is one per agent-minute (H14 scheme). $C(\tau)$ counts lagged pairs within agent-days. $T(\tau)$ is the non-reversible MLE. $t_k$ are implied timescales from eigenvalues $\lambda_k$. $\chi$ holds the PCCA+ memberships (Röblitz--Weber) of $m$ metastable sets. $q^\pm$ are forward and backward committors, with $\delta=0$ under detailed balance. $p_t$ are soft Jev posteriors.}

\end{gather*}\vspace{-7pt}}

\htelos{Nothing changes in practice for an operator: $t_2^*$ does not detect stuck periods. The ``metastable sets'' are tool modality (GUI vs shell) and idle time, which any log viewer shows. Part of the GUI-vs-shell split is a difference between GUI-heavy and shell-heavy agents. The transferable result is negative and is for analysts. Minute-scale agent behavior is non-Markov, so run the CK test before you quote a timescale. A pooled MSM over different agents makes false slow modes (pooled $t_2^*$ $\times$1.28 the per-agent median). Soft LLM labels need a noise-cancelling estimator and $\gtrsim$15k windows per period. On Jev states, waiting is the only slow set.}

\hbottom{On action classes and Jev states, the slowest behavior mode is acting vs waiting plus agent differences, and $t_2^*$ does not order periods by stuckness.}

\hcaveats{Round-1b synthetic checks show a bias of $\times$1.6--2.7 in the soft-state shifted estimator at a 4-h period's 3,600 windows. The estimator breaks down at 12 states below $\sim$15k windows. The soft CK test has no power, and a sojourn null on noisy argmax runs is invalid. The v3 per-period verdicts are therefore descriptive, and $t_2^*$ comparisons use equal-size subsamples. The NE41 control anchors are selected (active, censored). $p_{\rm blocked}$ means ``waiting on others'' in regime I and ``failing or looping'' in regime III. Pooled MSMs mix agents (rival R2).}
