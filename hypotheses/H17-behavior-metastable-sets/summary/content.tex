\hwhat{Is agent behavior a Markov state model (MSM) with a few slow metastable sets, and is its slowest timescale $t_2^*$ a per-period order parameter, slowest in stuck periods? Round 1 fitted MSMs on 6 action classes per active minute in 27 non-holdout periods: CK fails 27/27, $t_2^*$ (5--24 min) barely beats a sojourn null, does not track errors, and regime III is slower than regime I. Verdicts: 13 mixed, 14 failed. Round 1b (improved data) re-ran it on Jev v3.1 behavior states (soft vectors, a noise-cancelling estimator) with real failures instead of stderr. The semantic slowest mode is hours long (agent-day scale), the slow set is still acting vs.\ waiting, and higher $p_{\rm blocked}$ goes with \emph{shorter} $t_2^*$. Native tests (forced erasures, nudger switch-off, \#27's spontaneous shift) failed. Holdout not run.}

\hmodel{Kinetic Potts / non-equilibrium Markov chain (models 02, 10). State $x_t\in\{$browse, type, shell, chat, idle, consolidate$\}$ per agent-minute (H14 scheme); $C(\tau)$: lagged pair counts within agent-days; $T(\tau)$: non-reversible MLE; $t_k$: implied timescales from eigenvalues $\lambda_k$; $\chi$: PCCA+ memberships (Röblitz--Weber) of $m$ metastable sets; $q^\pm$: forward/backward committors, $\delta=0$ under detailed balance; $p_t$: soft (Jev) posteriors.}

\hmath{\vspace{-5pt}\footnotesize\setlength{\jot}{1pt}
\begin{gather*}
T_{ij}(\tau)=C_{ij}(\tau)\big/\textstyle\sum_k C_{ik}(\tau),\quad t_k(\tau)=-\tau/\ln|\lambda_k(T(\tau))|\\
t_2^*\equiv t_2(\tau_c=5\,\mathrm{min})\\
\text{CK: }P_{A\to A}(k\tau)\overset{?}{=}\big[\pi_A^{\top}T(\tau)^k\big]_A\\
T_{\rm cg}=(\chi^{\top}\Pi\chi)^{-1}\chi^{\top}\Pi T\chi,\quad \delta_i=q^+_i-(1-q^-_i)\\
\lambda_k^{\tau}=\mathrm{eig}\big[C(1)^{-1}C(1{+}\tau)\big],\quad C(\tau)=\textstyle\sum_t p_t\,p_{t+\tau}^{\top}
\end{gather*}\vspace{-7pt}}

\htelos{Candidly: a curiosity with one methodological payoff. The ``metastable sets'' are tool modality (GUI vs.\ shell) and idling, which any log viewer could tell you. Part of the GUI-vs-shell split is GUI-heavy vs.\ shell-heavy agents. $t_2^*$ is a stable, cheap period statistic, but it does not detect stuck periods (no link to error share or output), so an operator gains no monitor. The useful part is negative and transferable: minute-scale agent behavior is strongly non-Markov, pooled MSMs over heterogeneous agents manufacture slow modes, and noisy LLM labels need a noise-cancelling estimator and $\gtrsim$15k windows before any timescale means anything. The semantic (Jev) states, the content-level test, show no ``stuck'' attractor either: waiting is the only slow set.}

\hbottom{On action classes and on semantic Jev states alike, behavior's slowest mode is acting vs.\ waiting plus agent heterogeneity, and its timescale does not order periods by stuckness.}
