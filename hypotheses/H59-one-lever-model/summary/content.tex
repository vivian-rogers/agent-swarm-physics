\hwhat{The claim: one triple describes every operator input, namely field strength $h$, catalytic strength $\kappa$ and read-out delay $d$. A model fitted on three input classes should then predict the fourth. Each model call is idle, work or talk. Every nudge, human message (broadcast or named) and @-mention is timed at the call that first reads it (DQ1 ledger). Per period, one linear response with a shared kernel and field direction fits all classes. Each class is held out in turn (5 day folds). Replication: G51, G38, G04; natives: NE43, \#5 (G05), NE38. \textbf{The claim fails.} Held-out-class skill is 0.47 (nudges) and 0.72 (mentions) of a class-specific fit in G51, 0.06--0.75 in G04 and 0.12 for G38 nudges. At the read-out itself (0--2 calls), the shared shape keeps 77--100\% of the skill in G51 and for G04 humans. The classes differ in their tails. The holdout is not run.}

\hmodel{Kinetic response (model 02) with a field-catalyst split (H39), and kicks with a call-clock response kernel (model 09). Each transition's log-odds against staying has a baseline (agent, day, aging, Markov-2) plus a kick term. H59 gives each class a uniform catalyst $\kappa_c$ and a field $h_c$ along one shared direction $\theta$. One shared kernel $K_\ell$ runs over lags since the receiving call. Rivals: class-specific free responses, a class-specific direction, the read-out delay alone, the inert model.}

\htelos{Treat the immediate pull of an operator input as portable and its aftermath as class-specific. At the receiving call, every class pulls the agent toward talk, with a little extra traffic. A nudge and an @-mention look alike there (I$\to$T $+2.9$ for both in G51). One number per class plus the delay to the next model call therefore describes most of the immediate effect. The aftermath differs. Nudged agents stay idle-prone for 30 calls; this looks like the nudger selecting stuck agents, not a lever effect. Regime-I mentions speed up the work$\leftrightarrow$wait edge. Several messages read in one call count as one read (G05). The class levers do not change when the nudger stops (NE43).}

\hbottom{One triple per input class fails to predict a held-out class; classes share only the read-out-call response and differ in their tails.}

\hcaveats{The read-out/tail split is post hoc; it is frozen for the holdout as C1. The state space is behavioral only and holds no content fields. The baseline is fitted once and held fixed in the bootstraps. Named-human (92 reads) and G38 broadcast-human cells are uninformative. Kickoffs are not testable at call level. The nudge tail may be the nudger's targeting, which the past-only baseline cannot see.}
