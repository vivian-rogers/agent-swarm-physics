\hwhat{Round 2 asked whether groups of agents plus their shared artifacts form \emph{effective superagents}: units that use Kolchinsky--Wolpert (KW) semantic information to stay viable, with that information held at the group level. Tested on the work ledger (58k strict git/deploy writes) in 19 non-holdout units (\#30--\#51). Candidates were coordination-based (artifact crews, behavior-synchrony, co-allocation and reply communities), with rooms and labs as baselines. \textbf{No candidate is an individuality maximum} (crews' Stouffer $Z=+0.06$; 2--8\% local maxima). None carries KW semantic information about its environment ($\Delta V_{st}>0$ in 2/19 units, $\Delta V_{obs}$ in 0/19), and none repairs itself beyond aggregation. Allocation does persist across nights ($\Delta C=0.47$) and memory loss (16/17), but single agents out-persist crews. A goal change cuts advancement by 0.39. Holdout tests (NE30, NE24) written, \textbf{not run}.}

\hmodel{Model 04 (KW semantic information) on a coarse-grained unit $G$ = members + shared artifacts $R_G$ + channel. State $x_b$: did $G$ advance $R_G$ in 30-min bin $b$. Environment $y_b$: the rest of the swarm's writes, and human or automated messages. $V$: advancement over horizon $\tau$. $p^f$: KW's coarse-graining scramble of $p(x_0,y_0)$. $A^*$: Krakauer et al.'s self-determined (organismal) predictive information; $\iota$: its share of $H(x')$. $\Delta C$: return to the unit's artifacts after a night, versus a permutation null.}

\htelos{For someone running a swarm, the useful fact is a negative one: there is no group-level mind to steer. Coordination on artifacts adds no detectable self-maintenance beyond what the members already do. What persists is each agent's attachment to its own artifacts, which survives every context erasure and memory loss, and the operator's goal sets the work rate. The practical lever is therefore the artifact and the prompt, not the team. To keep work going across resets, make the work state legible in the repo; don't count on memory or on group culture. Do teams matter? Not measurably here. The whole KW apparatus returns values near zero on this instrument, which is partly a limit of the instrument: the ledger counts attempts, not outcomes.}

\hbottom{No effective superagents: the persistent unit is an agent plus its own artifact, driven by the prompt, and grouping adds no detectable agency.}

\hcaveats{No replay. Goal changes bundle a new instruction with the scramble, and the only artifact-store scramble (NE24) is held out. The KW values rest on a coarse Markov kernel whose bootstrap is anti-conservative under hidden state, and the binary state can't see \emph{which} artifact a unit works on. The ledger counts attempts (no failures, value or non-git work). Memory-loss evidence is 17 events, mostly in \#51, where private goals can carry continuity.}
