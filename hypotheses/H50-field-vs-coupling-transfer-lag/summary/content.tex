\hwhat{Do agents co-move because a common input hits everyone (a field) or because they read each other (a coupling)? In call cycles, a field moves every agent at its next call; a coupling acts only at the recipient's first call that can read the message. We used the DQ1 context ledger to compare calls that start just after a message with calls just before it (a placebo-corrected discontinuity, hop by hop), fitted input impulse responses, and decomposed co-movement on 71 non-holdout units (35 periods), with synthetic swarms first. Result: \textbf{activity co-movement is the schedule} (day start and stop explain about 0.6 beyond a null). \textbf{Talk co-movement is a gated coupling}: a peer message raises the chance that the next call is a talk call (45/71 units, none negative), always at hop 1, and this accounts for roughly all talk co-movement. HH167's regime split fails. Holdout not run.}

\hmodel{Gated linear response (models 02, 01). Each agent makes calls $c$ at times $t_c$; a message posted at $t_m$ enters context at the first call with $t_c>t_m$ (hop 1). Call outcome $Y_c$ (talk, work, idle) responds to inputs $u_{c-k}$ (bookends, human messages, nudges, platform errors) and peer messages $m_{c-k}$ first read $k$ hops earlier. $s$: call start minus message time (bandwidth 1.5 median call intervals); $e_{it}$: agent-day-demeaned minute activity or talk; $S$: equal-time co-movement.}

\hmath{\vspace{-6pt}\begin{gather*}
\mathrm{logit}\,P(Y_c{=}1)=h_i+\textstyle\sum_k g(k)\,u_{c-k}+\sum_k J(k)\,m_{c-k}\\
J_k=E[Y\,|\,s\!\to\!0^+]-E[Y\,|\,s\!\to\!0^-]-\text{placebo},\quad \delta(h)=\textstyle\sum_{k\le h}J_k\\
S=\textstyle\sum_t\big[(\sum_i e_{it})^2-\sum_i e_{it}^2\big]\big/\sum_t\sum_i e_{it}^2
\end{gather*}\vspace{-8pt}}

\htelos{Useful, mostly as a correction to how swarm synchrony is read. Most of the collective mode in \emph{activity} is the platform starting and stopping everyone; it says nothing about agents influencing each other. Influence is real but narrow. It acts at the next call, turns a work call into a talk call, and in the always-on regime it mostly needs the recipient to be named (jump 0.17 vs 0.004). For an operator: synchrony in who is busy is a scheduler artifact; to propagate something, address agents by name and expect a response within one call (about 15--25 s, minutes if paused). The nudger moves single agents and leaves the collective mode alone. Bookend messages are announcements, not inputs.}

\hbottom{In LLM swarms, ``moving together'' in activity is a field set by the scheduler, while talk propagates by a coupling gated at exactly one read-out call, which agents rarely relay beyond that.}
