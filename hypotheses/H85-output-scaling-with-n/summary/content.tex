\hwhat{The test asks how the swarm's outputs scale with its active population $N$. Each of 71 non-holdout period units gives one point: output per scheduled hour against $N$, with regime intercepts and goal-cluster bootstrap CIs. Talk is sublinear: messages scale as $N^{0.33}$ [$-0.18$, 0.64], and in regime I the room's talk volume is nearly fixed ($\beta=0.09$). Addressing per message rises as $N^{0.79}$ [0.41, 1.39], against $0.44$ predicted from H18's dilution and the measured pending set ($k\propto N^{1.29}$). Reply parents per message do not rise (0.02), so the HH's reply kill fires. Work exponents are not identified. The holdout script exists and is not run.}

\hmodel{Allometric scaling (model 14) with a per-call response kernel (model 02). $Y_u$ is a unit's total output, $T_u$ its scheduled hours, $N_u$ its hour-weighted active population. $\alpha_r$ is a regime intercept and $\zeta_g$ a goal-period effect. Responses per talk call scale as $k^{1-\beta_d}$ with pending set $k\propto N^{\gamma_k}$ and H18's $\beta_d=0.66$. DQ2 keeps one reply parent per message, which caps reply counts.}

\hmath{\vspace{-6pt}\begin{gather*}
\ln(Y_u/T_u)=\alpha_{r(u)}+\beta_Y\ln N_u+\zeta_{g(u)}+e_u\\
\beta_{\rm ment}-\beta_{\rm msg}=(1-\beta_d)\,\gamma_k,\qquad
\beta_{\rm reply}-\beta_{\rm msg}\approx(1-\beta_d)\,\gamma_k\,\frac{\lambda(1-f)}{f},\ \ f=1-e^{-\lambda}
\end{gather*}\vspace{-8pt}}

\hobs{../figures/summary_obs.pdf}{(a) Messages per scheduled hour against active population, one point per unit, colored by regime, with within-regime fits. Regime I is flat: more agents do not add talk. (b) Addressed agents per message against $N$. It rises in every regime, steepest in regime I.}

\htelos{Do not expect more talk from more agents. In regime I each agent kept its call clock, but its share of talking calls fell as $N^{-0.89}$, so the room's message rate stayed near 130 per hour (IQR 96--148) from 4 to 11 agents. In regime III talk grows as $N^{0.77}$. A message in a larger room names more agents: addressing per message grows as $N^{0.5}$ to $N^{0.8}$. Expect it, and route long rosters into rooms: within a day, the larger room talks less per agent (room exponent 0.36 in \#38). Do not read reply-graph density as interaction load: reply parents per message stay flat in $N$ (median 0.35 in regime I, 0.51 in III). Budget $\pm0.5$ on any output exponent fitted across goal periods.}

\hbottom{Talk is a shared, nearly fixed channel, not a per-agent output: messages scale as $N^{0.33}$ while addressing per message rises as dilution predicts.}
