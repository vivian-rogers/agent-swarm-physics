\hwhat{H79 asks if the village's artifacts form an autocatalytic set when agents are not catalysts. A reaction is a write to repo $X$ in a session where repo $Y$'s code runs first; cron streams catalyse their own repo. We built the network for G51, G31, G38 and G41, and for the natives G40 and NE29. Self-catalysis carries 85--99\% of maxRAF commits. No period has a catalytic cycle of length $\ge3$ with $\ge3$ events per edge. G51 has fewer such cycles than the rewired null ($p=0.01$). The maxRAF covers 21--40\% of agent work commits, so P1 ($\le20\%$) fails. This coverage equals the execution share and the rewired null, and it falls to 0.3--14\% without python heads. Executions follow writes more often than they precede them. Holdout script frozen, not run.}

\hmodel{Model 05 (replicators), RAF variant. Species: repos. Reaction $r=(X,Y)$: product $X$, catalyst $Y$, aggregated over session events. Food $F$: platforms, pre-period artifacts, operator-named artifacts. Agents are the uncatalysed background: their products are reactants, never catalysts. A maxRAF reaction needs $Y\in F$ or $Y$ produced inside the set. Order parameters: coverage $c$, self share $s$, supported cycles $n_3$, time ratio $\tau$.}

\hmath{\vspace{-5pt}\begin{gather*}
\mathcal R'\ \text{RAF}\iff \forall r=(X,Y)\in\mathcal R':\ Y\in F\cup\{X':(X',Y')\in\mathcal R'\}\\
c=\frac{\sum_{e:\,r(e)\in\mathrm{maxRAF}} n_e}{\sum_e n_e},\qquad s=\frac{\sum_{r=(X,X)} n_r}{\sum_{r\in\mathrm{maxRAF}} n_r}\\
\text{irrRAF}_{|\cdot|\ge2}=\text{simple cycle in } G=\{Y\!\to\!X:\ X,Y\notin F,\ X\neq Y\}\\
\tau=\frac{\#\{\text{commits with a repo run before the write}\}}{\#\{\text{commits with a repo run after the write}\}}
\end{gather*}\vspace{-7pt}}

\htelos{For an operator, the automata that agents build are single scripts that maintain their own repo. They do not form a self-sustaining tool ecosystem. When an agent leaves, nothing others depend on stops: the retiree's 120 repos catalysed 0 later commits. To audit what keeps running without agents, list the self-writing streams per repo. The G51 cron stream alone made 54,892 commits. A dependency-graph search for tool chains adds nothing to that list. The catalysis edge also points the wrong way in time, because agents mostly commit and then run code. So "this tool produced that work" cannot be read from session co-occurrence. This result is mostly a negative for the egregore reading.}

\hbottom{Artifact catalysis in the village is first order: self-maintaining scripts and repos, no cross-catalytic cycles, and execution that follows writes rather than causes them.}
