\hwhat{Per 30-min window and room, each agent's state is the project it touches most (strict artifact mentions). A uniform Curie--Weiss Potts model was fitted per week in 14 non-holdout weeks (3 more lacked labels). Prediction: the sign of $\beta J$ follows the goal mode, negative (division of labor) for divisible shared goals. \textbf{It failed:} $\beta J_{CW}>0$ in 11/14 weeks whatever the mode, including all 5 predicted-AF weeks ($+2.0$ to $+5.0$); the mode rule got 5/11 signs right ($p=0.73$). The coupling beyond each agent's own preferences beats circular-shift and day-permutation nulls in 10/14 weeks and predicts held-out days in 8/10. Spread appears only in the three own-artifact weeks (\#39, \#40, \#42), as fixed specialization, not avoidance. No project consensus was a first-order jump (0/4). The \#26 runoff vote did jump (0.18 $\to$ 0.80 in one window), but its coupling sits at threshold (2.8 [0.65, 4.65] vs 2.75). Holdout test frozen, not run.}

\hmodel{Model 10 (Potts), Curie--Weiss form. Spin $\sigma_i\in\{0,1..q\}$: agent $i$'s project in a window ($q\le 8$; 0 = rare projects, uncoupled); $b$ a room block of $N_b$ agents. $h_a$: period-level popularity field of project $a$; $\beta J$: one uniform coupling ($>0$ herding, $<0$ division of labor). $x_a$: share of agents on $a$. $\beta J_c$, $\beta J_s$: mean-field first-order point and ordered spinodal (2.77, 2.75 at $q=3$). A variant with agent fields $h_i(a)$ separates coupling from specialization.}

\hmath{\vspace{-8pt}\begin{gather*}
P(\boldsymbol\sigma)\propto\exp\Big[\sum_i h_{\sigma_i}+\frac{\beta J}{N_b-1}\sum_{i<j\in b}\delta_{\sigma_i\sigma_j}\,[\sigma_i\ge 1]\Big]\\
x_a=\operatorname{softmax}_a\!\left(h_a+\beta J\,x_a\right),\quad x_1:\ \tfrac1q\to\tfrac{q-1}{q}\ \text{at }\beta J_c\\
\beta J_c=\tfrac{2(q-1)\ln(q-1)}{q-2},\ \ \beta J_s=\min_s\tfrac1s\ln\tfrac{1+(q-1)s}{1-s}
\end{gather*}\vspace{-10pt}}

\htelos{The default is herding. Give LLM agents a shared goal with divisible subtasks and they still pile onto whichever repo or document is hot, in the same half-hour, beyond their stable preferences. Division of labor appeared only when the task itself handed each agent its own artifact. That is a usable but unsurprising design rule: if you want parallel work, assign ownership; don't expect the goal text to produce it. The coupling-beyond-fields $z$ is cheap to compute from artifact links on any swarm log, as a duplicated-work alarm. The Potts machinery bought little: no clean phase transition, and the one jump (\#26) is a voting-protocol step. Drive and coupling are not separated, so ``herding'' may just be everyone answering the same prompt.}

\hbottom{Goal wording does not set the sign of the coupling: LLM agents herd onto shared artifacts by default and spread out only when the task gives each one its own.}
