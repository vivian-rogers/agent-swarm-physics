\hwhat{The spin is the project that an agent touches most in a 30-min window and room (strict artifact mentions). A uniform Curie--Weiss Potts model is fitted per week in 14 non-holdout weeks. The prediction: the sign of $\beta J$ follows the goal mode. \textbf{It fails}: $\beta J_{CW}>0$ in 11/14 weeks whatever the mode (mode rule 5/11 signs, $p=0.73$). Coupling beyond each agent's own preferences beats circular-shift and day nulls in 10/11 shared-artifact weeks. Spread appears only in own-artifact weeks, as fixed specialization. \textbf{Round 1b} (deterministic labels, DQ4 work ledger, DQ6 ballots) changes no verdict. Agents' \emph{work commits} herd too: in 4/6 shared weeks, onto the repos they attend (same repo in 84\% of agent-windows). The claim that attention herds while work stays private therefore fails, except in own-artifact and private-role weeks. On the correct \#26 election the runoff jumps from 1/3 to 7/8 in 83 s.}

\hmodel{Model 10 (Potts) in Curie--Weiss form. The spin $\sigma_i\in\{0,1..q\}$ is agent $i$'s project in a window ($q\le 8$; 0 = rare projects, uncoupled). It comes from artifact mentions (attention) or, in round 1b, from agent work commits (work). $b$ is a room block of $N_b$ agents. $h_a$ is the popularity field of project $a$. $\beta J$ is one uniform coupling: $>0$ is herding, $<0$ division of labor. $\beta J_c$ and $\beta J_s$ are the mean-field first-order point and the ordered spinodal. A variant with agent fields $h_i(a)$ separates coupling from specialization.}

\hmath{\vspace{-8pt}\begin{gather*}
P(\boldsymbol\sigma)\propto\exp\Big[\sum_i h_{\sigma_i}+\frac{\beta J}{N_b-1}\sum_{i<j\in b}\delta_{\sigma_i\sigma_j}\,[\sigma_i\ge 1]\Big]\\
x_a=\operatorname{softmax}_a\!\left(h_a+\beta J\,x_a\right),\quad x_1:\ \tfrac1q\to\tfrac{q-1}{q}\ \text{at }\beta J_c\\
\beta J_c=\tfrac{2(q-1)\ln(q-1)}{q-2},\ \ \beta J_s=\min_s\tfrac1s\ln\tfrac{1+(q-1)s}{1-s}
\end{gather*}\vspace{-10pt}}

\htelos{Herding is the default, and it is real work, not only attention. In shared-artifact weeks agents commit to the same repos in the same half-hour, beyond their stable preferences. Their attention labels point at the repos they commit to (84\% of agent-windows). Division of labor appears only when the task gives each agent its own artifact or role. There agents still read each other's work more than they contribute to it. To get parallel work, assign ownership (a post hoc rule). The coupling-beyond-fields $z$ on artifact links is a cheap monitor for duplicated work: $z\ge2$ flags herding in commits in 4/6 shared weeks. The Potts machinery adds little: no clean phase transition, no separation of drive and coupling, and the one jump (\#26) looks like a ballot cascade.}

\hbottom{LLM agents herd onto shared artifacts by default, in commits and in attention, and spread out only when the task gives each agent its own.}
