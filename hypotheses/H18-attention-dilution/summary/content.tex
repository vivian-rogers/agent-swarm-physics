\hwhat{At each talk turn of an agent, we count the $k$ messages that reached it since its previous talk turn. We ask whether it responds to each pending sender, fitting within agent-days in 16 non-holdout goal periods. Round 1b recounts $k$ on the context ledger (which model call received which message) and adds reply labels. Response falls with $k$ in 16/16 periods: pooled $\hat\beta=0.66\pm0.02$ (round 1: 0.63). The curve saturates or follows recency; a budget-like shape wins 6/16. In \#51, timer-wake batches of exogenous size give $\hat\beta=0.45$. Per-pair uptake falls with room size across periods ($\rho=-0.57$) and across \#51's roster growth ($\rho\approx-0.8$). The round-1 placebo failure was mostly the visibility rule. Invisible senders now get addressed at half the pending rate (was 85\%); conversation state explains the rest. The merge and fetch-limit tests fail. The holdout is not run.}

\hmodel{Mean-field coupling (01) with per-pair cross-excitation (09). At a talk turn of recipient $i$, the agent takes up each pending message $m$ with hazard $\theta_{i,d}h_m$. It responds to sender $j$ (a name or a reply parent) if it takes up any message of $j$. $\theta_{i,d}$: agent$\times$day propensity. $h$: the attention rule (constant, $1/k$, saturating with $k_0$, recency with $\rho$, power $\beta$). $\gamma$: boost for messages naming $i$. $J_{ij}$: per-pair coupling. $N$: room size. $B$: senders responded to per turn.}

\hmath{\vspace{-5pt}\begin{gather*}
P(r_{\tau j}=1)=1-\exp\Big(-\theta_{i,d}\textstyle\sum_{m\in P_j(\tau)}h_m\Big)\\
h_m=e^{\gamma\,\mathbf 1[m\to i]}\times\Big\{1,\ \tfrac1k,\ \tfrac{1+k_0}{k_0+k},\ \rho^{\,\mathrm{rank}_m-1},\ k^{-\beta}\Big\}\\
J_{ij}\propto B\,k^{-\beta}\sim B\,N^{-\beta}\quad(\beta=1:\ \text{literal } J/N)
\end{gather*}\vspace{-7pt}}

\htelos{Expect per-pair engagement in a shared channel to fall as about $N^{-0.6}$ with room size $N$. Output per turn stays about the same, so a bigger room dilutes engagement and does not add collaboration. A reply goes to the newest pending messages. To raise within-room engagement, split the channel: the gain is about $(k$ ratio$)^{0.6}$, as at the \#35 split. This is a design rule, not a lever. It adds little to ``use fewer, smaller rooms'', and the exponent varies by period (0.52--0.80). The mention signal is now cleaner, because the placebo failure was mostly a visibility bug. It still carries conversation state.}

\hbottom{Correction (2026-10-04): the all-turn exponent ($\hat\beta\approx0.66$) is not separable from reactive timing (that null gives 0.75--0.80); the identified dilution is \#51's timer-wake batches, $k^{-0.50}\,[0.45, 0.56]$, where the null gives $\approx0$. So coupling scales sub-linearly, not as a literal $J/N$; replies go to the newest messages.}
