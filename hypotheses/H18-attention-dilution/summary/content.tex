\hwhat{At each talk turn we counted the $k$ messages that reached the agent since its previous talk turn and asked whether it responds to each pending sender, fitting within agent-days in 16 non-holdout goal periods. Round 1b recounts $k$ on the context ledger (which model call received which message) and adds reply labels. Response falls with $k$ in 16/16 periods: pooled $\hat\beta=0.66\pm0.02$ (round 1: 0.63). The curve saturates or follows recency; a literal $1/k$ wins 6/16. In \#51, timer-wake batches of exogenous size give 0.45. Per-pair uptake falls with room size across periods ($\rho=-0.57$) and across \#51's roster growth ($\rho\approx-0.8$). The round-1 placebo failure was mostly the visibility rule: invisible senders are now addressed at half the pending rate (was 85\%), the rest is conversation state. Merge and fetch-limit tests failed. Holdout not run.}

\hmodel{Mean-field coupling (model 01) with Hawkes-style per-pair cross-excitation (09). Each pending message $m$ at recipient $i$'s talk turn is ``taken up'' with hazard $\theta_{i,d}h_m$. Sender $j$ is responded to (named, or its message is the reply parent) if any of its messages is taken up. $\theta_{i,d}$: agent$\times$day propensity. $h$: the attention rule (constant, $1/k$, saturating with $k_0$, recency with $\rho$, power $\beta$). $\gamma$: boost for messages naming $i$. $J_{ij}$: per-pair coupling. $N$: room size. $B$: senders responded to per turn.}

\hmath{\vspace{-5pt}\begin{gather*}
P(r_{\tau j}=1)=1-\exp\Big(-\theta_{i,d}\textstyle\sum_{m\in P_j(\tau)}h_m\Big)\\
h_m=e^{\gamma\,\mathbf 1[m\to i]}\times\Big\{1,\ \tfrac1k,\ \tfrac{1+k_0}{k_0+k},\ \rho^{\,\mathrm{rank}_m-1},\ k^{-\beta}\Big\}\\
J_{ij}\propto B\,k^{-\beta}\sim B\,N^{-\beta}\quad(\beta=1:\ \text{literal } J/N)
\end{gather*}\vspace{-7pt}}

(a) Mentions: every period declines, more shallowly than $1/k$ (dotted). (b) Reply parents: steeper, close to $1/k$, because each message has one parent; which pending message gets it is decided mostly by recency.}

\htelos{For operators the usable fact is a scaling rule: in a shared channel, each agent's chance of engaging any one peer falls roughly as $N^{-0.6}$, while what it says per turn stays about the same. Bigger rooms get diluted, not more collaborative, and when an agent replies it replies to the newest messages. Splitting a channel raises within-room engagement by about $(k$ ratio$)^{0.6}$, as at \#35's split. A modest design rule, not a lever: it adds little to ``fewer, smaller rooms'', and the exponent varies by period. The mention signal is now cleaner (the placebo failure was mostly a visibility bug) but still carries conversation state.}

\hbottom{Attention in the village dilutes sub-linearly ($\hat\beta\approx0.66$ on corrected visibility), giving coupling $\propto N^{-0.6}$ rather than a literal $J/N$; replies go to the newest messages, and the placebo failure that clouded round 1 was mostly the visibility rule.}
