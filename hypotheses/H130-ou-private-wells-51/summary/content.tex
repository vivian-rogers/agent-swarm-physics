\hwhat{HH371 proposed the simplest kinetic version of H98's random field: each \#51 agent is an Ornstein--Uhlenbeck particle in its own well, every read is a small kick toward the sender, and the kick decays at the well's own rate. H130 measures both rates on the per-call clock in all 12 non-holdout \#51 units (45 days, 40,958 statements, 930k reads), with two embedding models. A read does kick: the read-minus-in-flight jump is $J_K=0.044$ [0.038, 0.050], positive in every unit with $\ge3$ days. The well relaxes at $\gamma_{\rm auto}=0.0094$ per call ($\approx$100 calls, 1 h), the same in every unit. The kick fades $\approx15\times$ faster ($\rho_\gamma$ 14.8, 90\% CI [7.2, 30.4]), so the one-rate kill fires. The holdout is not run.}

\hmodel{Vector OU dynamics on the call clock (model 11) with a measured response tested against fluctuations (model 02). $x_i$ is agent $i$'s 32-d whitened, style-residualized content minus its well centre $h_i$ (leave-day-out mean). $\gamma$ is the well stiffness per call, $\kappa$ the kick per read toward the sender's message $z_m$, $\xi$ the agent's own noise, $D_r$ a room drive. A linear system has one rate for response and memory; a kick held only in the context window would decay faster.}

\hmath{\vspace{-6pt}\begin{gather*}
x_i(n{+}1)=(1-\gamma)\,x_i(n)+\kappa\!\!\sum_{m\ {\rm read\ at}\ n}\!\!(z_m-h_i)+\xi_i(n)\\
C(\tau)=\langle x_B\!\cdot\!x_{B'}\rangle-C_\times(|t_{B'}-t_B|)\;\to\;\gamma_{\rm auto}\\
y_{Bj}=x_B\!\cdot\!\widehat{h_j-h_i}=\sum_b\beta_b R^{(j)}_b+\ldots\;\to\;\gamma_{\rm kick},\quad \rho_\gamma=\gamma_{\rm kick}/\gamma_{\rm auto}
\end{gather*}\vspace{-8pt}}

\htelos{For an operator, a message changes what a \#51-style agent says next, but only for its next few calls ($\approx$5 min): influence is a fast echo, not a lasting displacement. To move an agent's direction, repeat the input; one message decays within $\sim$7 calls, while the agent's own line persists $\sim$100 calls ($\approx$1 h) and survives context erasure. Expect pairs that read each other often to co-move more ($\beta_R\approx0.018$ per e-fold of reads), through repeated echoes.}

\hbottom{In \#51 a read pulls the next statement toward the sender (J$_K$ 0.044 [0.038, 0.050], 11/12 units, both models), but the pull fades about 15$\times$ faster ($\approx$7 calls) than the agent's own content memory ($\gamma_{\rm auto}$ 0.0094/call, homogeneous over 12 units).}
