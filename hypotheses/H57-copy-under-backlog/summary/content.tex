\hwhat{HH171 claims that agents under a large backlog echo what they read instead of transforming it. For every statement, the context ledger gives the messages read since the agent last spoke and the backlog $k$. The test asks whether near-copies of what was read rise with $k$ within agent. It runs on 34 non-holdout periods plus three native tests (NE42 merge/split, NE41 erasures, the \#51 N sweep). Synthetic worlds come first and expose seven estimator flaws. The pre-registered slopes are negative in 31/35 periods, but that is an artifact. Agents that post at the same moment write near-identical messages without reading each other. The most generous estimate (raw read-set echo) rises by at most $+0.0016$ per doubling of $k$, about 5\% of the synthetic H57 effect. Agents almost never near-copy the message they address. \textbf{Refuted.} The holdout script exists and is not run.}

\hmodel{Kolchinsky--Corominas-Murtra channel (model 08). A statement $B$ is the output; its source $A$ in the read set $R(B)$ is the input. Copy information counts $B$ reproducing $A$. Transformation information counts systematic dependence through change. H57 says the copy probability $\pi(k)$ rises with the backlog $k=|R|$. Mutually invisible pairs (posted while both calls ran) give the chance rate. Copying is coded at message level (near-copy), because cluster-level ``copying'' is topic coherence.}

I(X;Y)=I_{\rm copy}+I_{\rm tr},\quad I_{\rm copy}=\sum_x p(x)\,d\big(p(Y{=}x|x)\,\|\,p_Y(x)\big)\\
e_B=\mathbb{1}\big[\max_{A\in R(B)}\cos(A,B)\ge\tau\big]-\big[1-(1-\hat q)^{k}\big]\\

\end{gather*}\vspace{-8pt}}

\htelos{Do not count near-duplicate messages as copying. Most near-duplicates come from agents that respond to the same moment at the same time. An echo or ``groupthink'' monitor must compare near-duplicates with unread messages at the same lag; below 15\,s, unread pairs match read ones. This affects DQ5's cross-echo flag, H12's self-repetition and H07's ``copying dominates''. Backlog does not make agents parrot each other: echo rises by at most $+0.16$ points per doubling. Agents rephrase the named peer they answer. The Kolchinsky decomposition needs message-level coding; at topic level it reads coherence.}

\hbottom{Backlog does not make agents echo (at most $+0.16$ points per doubling); agents rephrase what they answer, and most near-duplication is simultaneous convergence, not copying.}

\hcaveats{The pre-registered estimator is invalid on real data, so the verdict rests on a post hoc upper bound and lag profiles. Near-copy thresholds come from two contrastive encoders truncated at 256 tokens. Rephrasing below threshold counts as transformation. The read set is the backlog since the last talk call; older in-context items can be copied too, and context load shows nothing either. The long-lag chance rate of the lag-matched estimator rests on few unread pairs. Backlog is observational, and the goal change confounds NE42. The 34 replication folders are one estimator, not 34 tests.}
