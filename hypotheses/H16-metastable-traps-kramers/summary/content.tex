\hwhat{Trap types (inactive spells, timer-pause chains, error loops, repeated-command loops) were tested in 11 non-holdout goal periods. Kramers predicts memoryless escape; instead traps \emph{age}: within agent the escape hazard falls roughly as $t^{-0.8}$ (G51 $\beta=-0.77$; G38 $-1.71$), and each re-pause lowers the odds of acting at the next timer expiry (G51 $-0.38$). One directed message during a pause raises those odds $\times$1.5--2.9 (5/7 periods); more add little. Round 1b (improved data) counted real failures instead of stderr, used the leading-@ nudge target and added Jev blocked and loop spells. ``Error loops age'' was largely a stderr artifact (rows $-51\%$; aging only in \#51, $-0.57$). Jev blocked spells age in \#51 and \#27; kick results are unchanged; with the nudger off (NE43) aging is unchanged. $\beta J_0=0.09$--$0.41$, no bistability. Holdout not run.}

\hmodel{Models 01/02 (mean field) plus Kramers escape. Agent activity $x$ moves in a double well $U(x)$ (idle and active basins) at temperature $T$. A trap is a stay in the idle basin, escaped at rate $k$ over barrier $\Delta U$ (attempt rate $\nu$). A kick (a message reaching the agent) adds force $f$. Swarm: Curie--Weiss coupling $J_0$, field $h$, active fraction $m$. Fitted: hazard $h_{it}$ with agent effects $\alpha_i$, aging slope $\beta$, dose effects $\gamma_n$.}

\hmath{\vspace{-5pt}\begin{gather*}
k=\nu\,e^{-\Delta U/T},\qquad G(x)=-\ln P(x)=U(x)/T+\text{const}\\
k(n)=k_0\,e^{nf/T}\ \text{(Kramers)}\quad\text{vs}\quad k(n)=k_0(1+c\,n)\ \text{(triggers)}\\
\ln\!\big[-\ln(1-h_{it})\big]=\alpha_i+\beta\ln t+\textstyle\sum_{n}\gamma_n\,\mathbb 1[\text{dose}_{it}=n]\\
f(m)=-\tfrac{1}{2}J_0m^2-hm-Ts(m);\ \text{bistable iff }\beta J_0(1-m^2)>1
\end{gather*}\vspace{-7pt}}

\htelos{Modestly useful, mostly as a correction. A stuck agent gets stickier the longer it sits, and switching the nudger off does not change that, so the deepening is the agent's own loop: intervene early. The lever that works is one directed message landing during a pause, read at the next timer expiry; repeats and room chatter add little, and under today's 5-min pause default a kick barely helps an agent deep in a pause chain. Messages never break failure loops; those need tooling or a reset. Real failure loops are rarer and shorter than stderr suggested. The physics added little: ``Kramers'' failed and ``aging plus saturating triggers'' is ordinary survival analysis.}

\hbottom{Agent traps are real and individual and they age by themselves (unchanged when the nudger stops), not by Kramers escape; kicks act as saturating triggers at timer gates, and real failure loops age only in the long \#51 window.}
