**Verdict:** descriptive
**Role:** exploratory
**Period:** #51. Events fixed before any statistic: HL1 Claude Opus 5 reassigned (NE38, 07-29 16:50 UTC); HL2 Gemini 2.5 Pro's tool-loss week (08-10 → 08-14); HL3 Gemini 2.5 Pro's bash failure (09-02 → 09-04); HL4 DeepSeek-V4-Pro's tool loss (09-02 → 09-04; HL4b 09-03 → 09-04).

## Why this period
A hub's departure removes its carriage of a pattern. A hub's vocabulary should die with it (β ≈ 1); a distributed ideology should be carried on by others (β < 0.5).

## Prediction
*Written 2026-10-09 (card), before running.* P2: β ≈ 1 for hub-centred memeplexes (h_K ≥ 0.6), β < 0.5 for distributed ones. K3: single events are descriptive unless beyond the placebo days' 95th percentile. Amendment A3 (before real data): any-weekday placebo days; only HL2 has size ≤ 0.10 and power ≥ 0.8.
