\hwhat{HH269 claims that memory size is a first-order homeostat with overshoot after erasures and a gain change at NE41. H71 fits the post-compression memory size from \texttt{memory\_stats} (62k non-holdout cycles, 37 units, regimes I--III). Each regime-III consolidation writes an append snapshot, then a compression snapshot. \textbf{Memory is a homeostat, but not first order, and it does not overshoot.} Size reverts toward an agent set point in 37/37 units ($\phi^+$ pooled 0.67 [0.63, 0.71] per cycle). H09's overshoot is the mixed sampling: the mixed series gives $\phi<0$ in 10/10 regime-III units while $\phi^+>0$. Forced and voluntary consolidations give the same $\phi^+$. AR(2) terms are positive (median +0.19). NE14 raises the set point (+17--31\%). The holdout script is not run.}

\hmodel{Model 04 (a maintained store) with model 05's import and removal bookkeeping. The degree of freedom is $x_n$, the log size of an agent's memory after compression $n$. Growth adds $\Delta_n$ (appends), and compression maps the peak $y_n$ back toward a set point $\mu_i$. A single first-order loop gives an AR(1) with gain $1-\phi$, where $\phi=b(1+c)$. The rivals are a random walk ($\phi=1$), a deadbeat template ($\phi=0$) and an over-correcting controller ($\phi<0$). A post hoc model adds a slowly drifting set point $m_n$.}

\hmath{\vspace{-6pt}\begin{gather*}
y_n=x_{n-1}+\Delta_n,\quad \Delta_n=d_i+c\,(x_{n-1}-\mu_i)+\xi_n\\
x_n=a_i+b\,y_n+\zeta_n,\qquad \phi=b(1+c)\\
x_n-\mu_i=\phi\,(x_{n-1}-\mu_i)+\varepsilon_n\\
\text{post hoc: } x_n=m_n+e_n,\ m_n=\rho_s m_{n-1}+\eta_n
\end{gather*}\vspace{-8pt}}

\htelos{For a scaffold builder, memory size is a regulated variable with a per-agent set point (agent identity holds 91\% of its variance, the lab 41\%). Agents restore it within a few consolidations, so a memory-size alarm needs a per-agent baseline, not a global cap. Forced erasures do not destabilize it. The NE14 scaffold change raised the set point by about 20\% and left the per-cycle gain almost unchanged, so a prompt change moves the target, not the loop. A monitor reading raw \texttt{memory\_stats} will see a false overshoot ($\phi\approx-0.5$) from the two-snapshot write. Filter to compression rows first. The result is a design fact about the scaffold's memory loop. It does not say what the memory is worth (H15: about 0 at day scale).}

\hbottom{Memory size is regulated toward an agent set point on the consolidation clock, without overshoot; the loop is a fast near-deadbeat compression around a slowly drifting target, not a first-order homeostat.}
