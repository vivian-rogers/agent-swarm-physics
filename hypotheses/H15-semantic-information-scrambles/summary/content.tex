\hwhat{Natural scrambles in non-holdout data, per goal period, against a placebo-day null (a synthetic check on the real village skeleton: calibrated, power 17--41\%). \textbf{Memory:} 12 losses of 50--80\% of an agent's memory and 20 newcomers with empty memories showed no day-scale cost on viability $V^*$: memory loss $-0.55$ SD [$-1.78$, $+0.68$] (2 periods), newcomers $+0.15$ [$-0.18$, $+0.47$] (\emph{more} engaged early); the rewrite control was null. \textbf{Chat cuts:} only 3 usable events. \textbf{Context:} consolidations wipe the context window (forced every 41 turns) but keep memory. The pre-registered forced-vs-voluntary contrast came out wrong-signed (task-phase confound). Post hoc, writes drop 33--53\% for $\sim$10 turns after a forced wipe in 8/9 regime III periods, however much was saved to memory. D2.6 found no homeostatic $V$. Holdout not run.}
\hmodel{Model 04, Kolchinsky--Wolpert semantic information. $X$ = one agent: memory $M$ (day-scale store) and context window $C$ (session-scale store, filled by chat and events); $Y$ = the rest of the village. Scrambles erase $M$ or $C$, or cut $Y\to X$; $\hat p$ = the scrambled joint. $V$ = viability per agent-day (5 candidates) or per turn (writes); $u$ = its same-day residual; $\delta$ = fraction removed; $S$, $\eta$ = semantic information, its share of $I(X;Y)$.}
\hmath{\vspace{-8pt}
\begin{gather*}
\Delta V = V[p]-V[\hat p],\qquad \kappa=\Delta V/\delta\\
S=\min_f I(\hat p^{f})\ \text{s.t.}\ V[\hat p^{f}]=V[p],\quad \eta=\tfrac{S}{I}\le 1-\delta^*\\
u_{ad}=V_{ad}-\overline{V}_{-a,d}\\
\widehat{\Delta V}=\bar u_{\rm post}-\big(\mu_a+\rho^{s}\,\mathbb{E}[h_{t_0-1}\mid u_{\rm pre}]\big)
\end{gather*}\vspace{-6pt}}

\htelos{Mostly confirms what people running LLM agents already suspect: the working context keeps an agent productive, and a long-term memory file is something it rebuilds from its environment within a day. The one usable number is the cost of a context reset, about 45\% of writes for $\sim$10 turns (about a tenth of output at a 41-turn cadence). The levers are a longer cap or a task-state summary carried across the reset; today's memory write doesn't recover the loss. That is scaffold engineering, not physics, and post-hoc until the holdout check (C3) runs. Kolchinsky--Wolpert adds vocabulary (stored vs.\ observed information) but here measured neither $S$ nor $\eta$, nor a viability function.}
\hbottom{Day-scale memory carries no detectable load-bearing information; the context window does (about $-45\%$ output for ten turns per forced wipe, post-hoc, awaiting the holdout).}
