\hwhat{We build a reusable daily dial: the Curie--Weiss loop gain $g=1-1/\mathrm{VR}$ and $T/T_c=1/g$ per day and channel, computed from logs. It masks stalls, removes slow drives and gives calibrated 90\% intervals. We run it on 282 non-holdout days. \textbf{Round 1b} repeats it on the corrected activity table (round 1 lost half of all events), with the DQ8 calibrated null. \textbf{Activity and talk are subcritical on every day}: median $g=0.16$ for both (was 0.10 and 0.12), $T/T_c\approx6$. Trimmed to the common running window, activity drops to 0.07 and beats the independent-agent ceiling on only 24\% of days. The dial now reproduces H19 on the same table ($\rho$ 0.94, 0.97) and tracks the Hawkes $\hat n$ of H03 ($\rho=0.46$). \textbf{Content still reads near-critical} (0.70; P1 failed): swarm size times a shared-field correlation. Drive withdrawal (NE43) leaves the dial unchanged. Talk co-activation vanishes when 15 agents share one room (NE42). The holdout is not run.}

\hmodel{Curie--Weiss (01), Hawkes (09) and O($n$) spins (11). Spin $s_i=\pm1$: agent $i$ active, or posting, in a minute. For content, $s_i$ is the 30-min mean of its whitened unit message embeddings ($n=32$). $h_i(t)$: private fields (schedule, goal), removed by 30-min block means and agent-day means; stalls are masked. $q_i=1-m_i^2$. Order parameter $g$: loop gain. VR: collective over independent variance. $\bar\rho$: mean pairwise correlation. $N$: agents that day.}

\hmath{\vspace{-8pt}\begin{gather*}
H=-\tfrac{J_0}{2N}\Big(\textstyle\sum_i s_i\Big)^2-\sum_i h_i(t)\,s_i,\qquad g=\beta J_0\,\bar q\\
\delta M=\frac{\sum_j q_j\beta\,\delta h_j}{1-g},\qquad \mathrm{VR}=\frac{\operatorname{Var}\sum_i s_i}{\sum_i\operatorname{Var}s_i}=\frac{1}{1-g}\\
g=1-\mathrm{VR}^{-1},\qquad T/T_c=1/g\ \ (h=0)\\
\mathrm{VR}-1=(N-1)\,\bar\rho\ \Rightarrow\ g(N)=\frac{(N-1)\bar\rho}{1+(N-1)\bar\rho}
\end{gather*}\vspace{-10pt}}

\htelos{Compute the dial from event logs with \texttt{compute\_dial}. In this village it says the swarm amplifies a nudge by 10--20\%: no fast runaway. Trim each day to the common running window before you read activity feedback. Without the trim, about half the activity ``signal'' is agents that boot together. Track the per-pair correlation $\bar\rho$ weekly, not $g$: at fixed $\bar\rho$, $g$ rises with headcount. A green dial does not exclude slow herding through context read minutes later. The talk dial is the credible gauge: it matches an independent Hawkes fit and survives the trim.}

\hbottom{The daily Curie--Weiss dial puts activity and talk far below criticality ($g\approx0.16$; activity 0.07 trimmed); near-critical content is size times a shared field.}
