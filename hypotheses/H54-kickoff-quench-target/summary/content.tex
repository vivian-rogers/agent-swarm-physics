\hwhat{We asked whether the kickoff text is the target a goal change quenches the swarm into. Each day-1 content centroid was scored against its own kickoff and 32 others (genericness-corrected swap null), plus four period-native tests. The centroid picks out its own kickoff (median percentile 1.0, top-1 in 18/33, $p=3\times10^{-6}$), and the day-1 move points at the new text in 23/25 periods. It fails only where the kickoff names no shared target: free weeks \#3 and \#16, \#44's half-free week, and \#51. In \#51 each agent lands on its own private goal (role-swap accuracy 0.95), and a human reassignment re-targets an agent within a day (+0.61). Nine of 13 kickoff-frozen projects carry the goal's words (enrichment 3.2); only one pre-existed. Text specificity does not predict spread, and families do not differ. Holdout not run.}

\hmodel{Model 11 with a quench: each agent's whitened statement vector $\mathbf s_i$ relaxes toward a target $\hat{\mathbf t}$ with depth $\lambda$, plus a persistent offset $\mathbf a_i$ (style, family, old project), herding $J\mathbf m$ and noise. H54 says $\hat{\mathbf t}$ is readable from the kickoff text: $\hat{\mathbf t}\approx\hat{\mathbf k}$, its embedding in the same basis. Model 10's version: the kickoff is a field on the projects it names, which freeze at once. Rivals: no target, inertia (old state, carry-over projects), kickoff genre, agent-authored plans, family fields.}

\htelos{Useful, with a limit. What you write in a kickoff is where a swarm's talk goes on day 1, and the project it freezes onto is the one carrying the goal's words. A private goal text pins each agent to its own target for weeks; rewriting one agent's goal moves that agent within a day. A choose-your-own-goal kickoff leaves no shared target and a more scattered swarm. The limit: how specific the text is (numbers, names, deadlines) did not tune how tightly agents cluster, so ``write a more specific prompt'' is not yet a validated dial. Agent-written plans, including an elected leader's goal announcement, did not act as targets the way human text did. Part of the effect is agents restating the kickoff, which is the mechanism, not a flaw.}

\hbottom{The kickoff (or private goal) text is the day-1 quench target and names the projects that freeze, but its specificity does not set how tightly the swarm clusters.}
