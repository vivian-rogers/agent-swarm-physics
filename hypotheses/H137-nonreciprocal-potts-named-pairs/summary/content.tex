\hwhat{HH380 says that a one-way name steers project choice: when agent $j$ names agent $i$ and $i$ does not name $j$ back, $i$ should join $j$'s project more often than $j$ joins $i$'s, so project hops break detailed balance only along one-way named pairs. H137 builds follow hops from the shared per-call project labels in 71 non-reserved units, classifies every agent pair by naming (one-way, mutual, none) and fits the follow direction against the naming direction with popularity controls. \textbf{The test cannot decide at village counts}: on real skeletons a coupling of $J=1$ moves one-way follow counts by 1--3\%, and the pooled power is 0.18. Descriptively, once each agent's hop propensity is controlled, follow direction does not track naming ($\theta_\mathrm{name}=+0.01\,[-0.07,+0.08]$, 41 testable units).}

\hmodel{Models 10, 02 and 15. Kinetic Potts walker: at its call $c$ agent $i$ hops to project $b$ with utility $u_b=\kappa_b+\sum_j J\ln(1+R_{i\leftarrow j}(c))\,[\sigma_j(c)=b]+\text{habit}+\text{share}$, where $R_{i\leftarrow j}$ counts $j$'s messages naming $i$ read in $i$'s last 10 calls. Couplings exist only from named senders, so $J_{i\leftarrow j}\neq J_{j\leftarrow i}$ on one-way pairs, and the pair current runs from namer to named. The pair entropy production is Schnakenberg's edge term.}

\hcaveats{Every result is descriptive: S0 failed, so no statistic is a powered test, and both HH kills need power to fire.
