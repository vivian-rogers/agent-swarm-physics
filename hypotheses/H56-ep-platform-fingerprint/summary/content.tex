\hwhat{Does the entropy production (EP) of agents' turn-level action chains jump at scaffold changes (prompts, tools, harness) but not at goal, roster or room changes, so that EP flags undocumented platform changes? A within-agent, count-matched EP change over 3+3 days was computed at 107 dated events (changelog, NE catalog, kickoffs, joins, rooms) and at every day for blind change-point detection, on all records and on an agent-only chain with scaffold records removed. Synthetic chains came first: the estimator is calibrated and detects $\pm$50\% changes. On real data, scaffold changes do not stand out (0/17 tool-change hits; class $p=0.23$), not even NE14b ($-28\%$, $t=-1.3$) or the oracle swap (NE40), dated here to 04-20 from answer style ($t=-0.2$). Goal kickoffs move the agent-only chain more ($p=0.007$). Family differences survive scaffold removal. Holdout not run.}

\hmodel{Models 02/05: each agent is a Markov chain on H14's 11 action classes (or 6 coarse states). Its EP per transition is the pair-KL between forward and reversed transitions; the AIK bound on antisymmetric transition indicators $g_{ab}$ estimates it (Newton step, cross-fitted over days). H56 reads goal, roster and room changes as fields that move occupancy (potentials $U$), and scaffold changes as changes in the cycle forces $F$, so only the latter should change $\Sigma$.}

\hmath{\vspace{-5pt}\begin{gather*}
\Sigma=\sum_{a,b}\pi_aP_{ab}\ln\frac{\pi_aP_{ab}}{\pi_bP_{ba}},\qquad \ln\frac{P_{ab}}{P_{ba}}=F_{ab}+U_a-U_b\\
\hat\Sigma_N=\tfrac{2}{k(k-1)}\textstyle\sum_{f\neq f'}\bar g_f^{\top}K^{-1}\bar g_{f'},\quad g_{ab}=\mathbb 1[a\!\to\! b]-\mathbb 1[b\!\to\! a]\\
\Delta_i=\hat\Sigma_i(\text{post})-\hat\Sigma_i(\text{pre})\ \ \text{(both sides subsampled to }m_i=\min n\text{)}\\
t=\bar\Delta/\mathrm{SE}(\Delta_i),\qquad f_+=\#\{\Delta_i>0\}/n
\end{gather*}\vspace{-7pt}}

\htelos{Mostly a useful negative. An operator who hoped to watch one thermodynamic number for silent platform changes should not: behavioral EP tracks what agents are working on (goal kickoffs move it more than tool changes do), and families differ in tool-use style, not in harness. The undocumented changes we did find (the answerer swap on 04-20, a search-tool schema change on 07-29, a two-day search malfunction, the end of the operator's bookends on 08-04) all came from plain log features: event-type mix, tool-output formatting, schema fields. That is the practical monitor, and it is cheap. EP stays a descriptor of how directed agents' tool workflows are. One post hoc lead is worth a holdout check: at scaffold changes, agents' EP moves in the same direction more often than on random days.}

\hbottom{Entropy production of agents' action chains does not fingerprint the platform: scaffold changes, even the regime II$\to$III switch and an undocumented oracle swap, sit inside the day-to-day spread, which is set by the work agents do.}
