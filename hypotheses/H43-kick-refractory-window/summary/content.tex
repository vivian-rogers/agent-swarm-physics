\hwhat{H43 asked whether a kicked agent ignores a second kick until the task the first kick launched is over. Each kick is timed at the model call that first reads it (DQ1 ledger). Round 1 (35 non-reserved periods) found no refractory window: a second kick read by a later call keeps 80--130\% of a first kick's effect. Round 2 asks what the unit of operator attention is. Four tests ran, each validated first on synthetic outcomes over the real skeleton: the $k$-th kick inside one read, nudge facilitation against the nudger's own trigger, re-kicked timer wakes in every regime-III period, and the decomposition of the NE43 drop. In \#51 one read is one kick. A second directed item in the same call adds $\rho_2=0.11$ [0.01, 0.21] of the first; a kick read by the next call keeps about 0.7.}

\hmodel{Model 09 (renewal Hawkes with a recovery function) and model 03 (refractory compartment). The read-out call is the clock. \htelos{Do not stack kicks before the recipient's next model call. In \#51 a second directed message in the same read adds about a tenth of the first, and a third adds nothing. Merge them, or send the second after the next call; a kick read by the next call keeps about 70\%. Do not re-nudge an agent that ignored a nudge and is still in the same pause chain. Its escape rises only from 0.03 to 0.05. Wait until it has worked and stopped again; then a nudge works like a first one. Before blaming a lever for a swarm-level drop, split the drop into read cadence and escape per read. The NE43 drop was longer pauses.}

\hcaveats{The batching ratio is a \#51 result; elsewhere, talking at the call does not carry the read-out ($I^2$ 0.95). R2 has power 0.5, so neither facilitation nor its absence is shown. A trap that survived a first nudge is selected for non-response, so the same-trap loss is not identified as refractoriness. The large first-nudge effect at the wake (lnOR 1.0--1.7) is post hoc and model-dependent; it disagrees with round 1 and with H35's minute-level result. Small regime-III periods separate and need a post hoc prior. The NE43 decomposition is an accounting: what links the room merge to longer pauses is not identified.}
