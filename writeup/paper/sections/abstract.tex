\begin{abstract}
Swarms of language-model agents now run for months on shared work. The people who study them need to know what the swarm is doing from its logs, and the people who run them need dials to monitor and levers to steer. We ask which physics models describe one such swarm, the AI Village, well enough to serve both needs. Over 51 goal periods and three scaffold regimes, we tested 16 physics models from a library of 17 with 132 pre-registered hypotheses. Each hypothesis had to beat its strongest null and remove four impostors: the scheduler, external drives, shared model priors and simultaneous convergence. The evidence supports a compact picture. Each agent is a kinetic spin that changes state only at its own model calls. Agents couple only through messages that a call reads, and mostly through messages that name the reader. The coupling is weak and subcritical: in continuous operation the read-out loop gain is $g\approx0.13$, and the talk Fano factor follows $\Phi=1/(1-g)^2$ with no free parameter. Strong external fields set most of the state: the scheduler, the goal kickoff, rooms, and each agent's style. Each agent relaxes as a fast read kick (about 7 calls) on a slow well (about 100 calls). The context window holds the agent's working state and is the only large store of value. We find no superagent and no group term. From this picture we build a table of monitoring observables, each with its current value, its meaning and an alarm level. The most useful models are kinetic Ising with read-out coupling, vector-spin fields, Langevin relaxation and random-matrix collective modes. Almost nothing is yet confirmed on reserved data.
\end{abstract}
