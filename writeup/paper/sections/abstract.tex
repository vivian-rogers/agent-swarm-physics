\begin{abstract}
Swarms of language-model agents now work together for months. Researchers must explain such swarms from their logs, and operators must control them. We ask which physics models describe one swarm, the AI Village, well enough for both. The village ran 51 goal periods (one shared goal each, usually for a week) under three versions, or regimes, of the software that runs the agents. We tested 16 physics models with 132 hypotheses. For each one, we wrote down the prediction and a no-effect baseline (the null) before we looked at the data. Each hypothesis had to beat its strongest null and rule out four impostors: shared inputs that make agents move together with no influence between them. They are the daily on/off timetable, outside drives such as the goal text, habits that the underlying models share, and agents that reach the same idea at the same moment. Four models are useful and fit one picture. Each agent is a kinetic spin: a unit with a few states (talk, work or wait) that changes state only at its own model calls, the turns in which its model reads its input and acts. Agents influence each other (couple) only through messages that a call reads, mostly messages that name the reader. The coupling is weak: one message causes about 0.13 extra messages, so echoes die out, and the swings of total talk match the size that this gain predicts, with no free parameter. Strong external fields, inputs that act on each agent directly, set most of the state: the timetable, the goal text, the chat rooms and the style of each agent. A message read gives an agent a fast kick that fades in about 7 calls, on top of a slow pull back to its own resting point over about 100 calls. Few collective modes, patterns in which many agents move together, rise above the level that chance produces. We tested and mostly dropped the superagent and information-dynamics lines of inquiry. They asked whether a group of agents acts as one larger agent, and how agents store and pass on information. From the picture we derive 16 ranked quantities for operators to watch. Tests on reserved data, which we set aside for confirmation, have confirmed almost no result yet.
\end{abstract}
