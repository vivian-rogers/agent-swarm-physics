\section{Introduction}\label{sec:intro}

\textbf{1. The problem.} Groups of language-model agents now work together for weeks or months. They share computers, files and a chat. We call such a group a \emph{swarm}. Researchers in interpretability must explain, from the logs, what a swarm does and why. Operators must control a swarm: they must know which numbers to watch and which levers to use. Both groups need a description that is much smaller than the logs and that can still predict.

\textbf{2. Why the problem is hard.} Three facts make the task difficult.
\begin{tightitem}
\item \emph{Agents share inputs.} The same model weights, goal text and schedule act on all agents. Thus agents move together, also when they do not interact.
\item \emph{Correlation is not influence.} When two agents write similar text, one agent can copy the other, or both can react to the same input. The logs alone do not show which.
\item \emph{There is no ground-truth model.} Nobody wrote the rules of the swarm. Many models can fit the same record, and a good fit does not show that a model is correct.
\end{tightitem}

\textbf{3. Our approach.} Statistical physics gives small descriptions of systems with many parts that interact. A magnet has about $10^{23}$ \emph{spins}, parts with few states, but a few numbers predict its response. A \emph{field} is an external drive that acts on each part directly. A \emph{coupling} is an interaction between two parts. A field can align parts that never interact, so the first question for each pattern is: field or coupling? Sociophysics applies these ideas to human groups~\cite{castellano2009}.

Recent work applies statistical mechanics to language-model agents directly. El \emph{et al.} studied more than 10\,000 designed communities of agents that exchange messages and revise opinions on fixed questions~\cite{el2026physics}. In their model, each agent tends to move to lower social pressure, and this model predicts individual trajectories. They also found that the communities operate below a critical temperature, which agrees with our subcritical loop gain. Their approach is different from ours, and their model is very simple: one opinion per agent, pairwise ties and one temperature. Our swarm is one open deployment over 18 months. There, external fields, read-out timing and context memory control the dynamics, and pairwise ties alone do not predict the data.

We use physics models as candidate \emph{effective theories}: small models that predict the data at the scale that we can observe. We tested each model with five rules.
\begin{tightenum}
\item \emph{Pre-registered predictions.} Each hypothesis has a dated prediction, a null model (the simplest model with no effect) and a kill rule before it uses real data.
\item \emph{Impostor checks.} Each claim must remove four impostors that make a field look like a coupling: the scheduler, external drives, shared model priors and simultaneous convergence.
\item \emph{Natural experiments.} We cannot run new swarms, so dated changes of scaffold, roster, rooms and operator behavior are our interventions.
\item \emph{Faithfulness scores.} A model must beat its strongest null and predict a statistic that it did not fit.
\item \emph{Reserved data.} We kept 16 goal periods and four natural-experiment windows for confirmation.
\end{tightenum}

\textbf{4. The system and the data.} The AI Village is a public record of one swarm, run by AI Digest~\cite{aivillage}. From April 2025 to September 2026, 46 frontier agents from several labs worked on 51 shared goals (Fig.~\ref{fig:timeline}). A \emph{goal period} is the time for one goal, usually one working week; it is our unit of analysis. The agents use browsers, shells and a group chat.

The \emph{scaffold} is the software that runs the agents. Three scaffold changes divide the record into three \emph{regimes}:
\begin{tightitem}
\item regime I: one chat room for all agents, in daily sessions;
\item regime II: several rooms, still in sessions;
\item regime III: continuous operation; each agent sees only its own room.
\end{tightitem}
The record holds 381k timeline events and 173k agent chat messages. We tested 16 physics models from a library of 17, with 132 hypotheses. Claude agents wrote, pre-registered, ran and scored the hypotheses, and the second author reviewed the work.

\textbf{5. What we found.} Four models are useful, and they combine into one picture (Sec.~\ref{sec:picture}).
\begin{tightenum}
\item Each agent is a kinetic spin: it changes state only at its own model calls.
\item Agents couple only through messages that a call reads, mostly messages that name the reader.
\item The coupling is weak: one message causes about 0.13 extra messages, so echoes decay.
\item Strong external fields set most of the state: the scheduler, the goal text, the rooms and the style of each agent.
\item Each agent relaxes as a fast kick of about 7 calls on a slow well of about 100 calls.
\item Few collective modes rise above the noise.
\end{tightenum}
All of these results are exploratory. Tests on reserved data have confirmed almost none of them.

\textbf{6. Why this matters.} For interpretability, the picture tells where to look. Divide each pattern of co-movement into field and coupling, and find the memory of an agent in its context window. For control, the picture gives 16 observables with current values and use cases (Table~\ref{tab:monitor}). It also sizes the levers. Field levers, such as the kickoff text and context resets, are large. Message levers, such as nudges, are small, but a name multiplies the effect of a message about 19 times.
