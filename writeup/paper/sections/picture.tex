\section{What the system is}\label{sec:picture}

This section states the picture that the evidence supports, in seven lines. Each line names the physics model that carries it and the strongest cards; Sec.~\ref{sec:models} gives the evidence. Read the picture as a working model with error bars. It is not confirmed on reserved data. Two terms recur. The \emph{read-out call} of a message is the first model call of an agent whose context holds the message. A message that arrives while a call runs is \emph{in flight}; it cannot enter that call.

\begin{enumerate}
\item \textbf{Agents are kinetic spins on a call clock} (model 02). At each model call an agent has an action class (talk, work or wait), a content vector and a project. It changes state only at its calls. In regimes II and III the coupling per call does not depend on how long the call took, so the clock is the call, not the wall clock (H40: elasticity $\eta_{\rm rep|talk}=-0.11$ [$-0.16$, $-0.06$]; a wall clock, $\eta=1$, is excluded). Regime I, the early chat scaffold, does not follow this rule.
\item \textbf{Coupling acts only through messages read at a call, mostly named ones} (model 02). The chance that an agent names or answers a sender jumps at the read-out call and not before it (H08: 14/17 periods for mentions, 17/17 for replies). A read that names the reader adds 0.079 [0.069, 0.089] talk calls; an unnamed read adds 0.004 [0.003, 0.006], a ratio of about 19 (H67). Content moves the same way, five times more for named messages (H50).
\item \textbf{The coupling is weak and subcritical} (models 01, 02, 09, 03). In continuous operation the read-out loop gain is $g=0.13$ (H67). The fluctuations of talk give the same number with no fit, $g_{\rm Fano}=0.149$ [0.123, 0.175] (H67 with H111). A push is amplified by $\chi=1/(1-g)\approx1.15$, and by at most 1.31 in any goal period (H51). Ideas spread with a branching ratio near 0.2 (H34).
\item \textbf{Strong external fields dominate} (models 11, 01, 15). The scheduler's daily start and stop give 70--80\% of the co-activation in regime III (H38). The kickoff text is the target of each agent's day-1 content (H54). Rooms split content into domains (H100). Style marks each agent well enough to identify it (H46). A goal change acts as a quench, not as a small linear push (H10, H96).
\item \textbf{Each agent relaxes as a fast read kick on a slow well} (model 16). A read pulls the reader's next statement toward the sender, and the pull decays in about 7 calls. The agent's own content returns to its well over about 100 calls, roughly 1\,h (H130). After a kickoff the response is overdamped: day 1 overshoots, and nothing undershoots (H125).
\item \textbf{The context window holds the working state, and it is the only large store of value} (model 04). A forced erasure of the context costs 39\% of committed work over the next 10 calls (H15). Per bit of allocation information, the context window buys $\kappa_C=5.2$ [3.8, 7.9] commits per 20 calls (H87). Memory notes, chat reads and history search carry almost no measured value. Idle traps and restatement loops also live in the context (H16, H69).
\item \textbf{There is no superagent and no group term} (models 04, 12, 13, 17). No group that shares work persists as a unit beyond its members and their own files (H01, H58). Pairs and fields account for shared vocabulary (H101), and content changes by transmission among the agents who stay (H89). The one exception is a slow content mode in the early single-room village (H81).
\end{enumerate}

\textbf{The effective model.} Two equations hold the picture. For the action of agent $i$ at its call $c$, the read-out kinetic Ising model of Sec.~\ref{sec:m02} gives
\begin{equation}
P(Y_{ic}=1)=\sigma\Big(h_i(t_{ic})+\!\!\sum_{m\in B_{ic}}\!\!\big[J_0+J_{\rm N}\,\mathbb 1(m\ \text{names}\ i)\big]\Big),
\label{eq:pic-kinetic}
\end{equation}
where $\sigma$ is the logistic function, $h_i$ collects the fields (scheduler, goal, room, agent) and $B_{ic}$ is the batch of messages that the call reads. Only the reads enter, and $J_{\rm N}\gg J_0$. For the content vector $x_i=s_i+k_i$ of the agent at call $n$, the two-rate Langevin model of Sec.~\ref{sec:m16} gives
\begin{align}
s_i(n+1)-c_i&=(1-\gamma_s)\,\big(s_i(n)-c_i\big)+\xi_i(n),\nonumber\\
k_i(n+1)&=(1-\gamma_k)\,k_i(n)+\kappa\!\!\sum_{m\in B_{in}}\!\!(z_m-x_i)_\perp ,
\label{eq:pic-langevin}
\end{align}
with a well centre $c_i$ set by the kickoff, the room and the agent, message content $z_m$, and $\gamma_k/\gamma_s\approx15$. Everything else in this paper is a test of, or a correction to, these two lines. Figure~\ref{fig:picture} draws them.

\subsection{Monitoring observables}\label{sec:observables}

The picture turns into dials (Table~\ref{tab:observables}). Each dial is a single number per goal period or per week-long window, computed from logs that any swarm can keep: model calls with timestamps, messages with recipients, what each call could read, commits, and statement embeddings. The loop gain plays the role of $T/T_c$. Its distance to criticality, $1/(1-g)$, says how much a local push is amplified; the Fano rule checks it from fluctuations alone. The field share and the kickoff alignment say how much of the swarm's order comes from outside. The well depth and the two time constants say how fast the swarm forgets and how long a message acts. The random-matrix edge counts the collective modes that exist beyond noise. The value per bit of the context window prices an erasure.

Two dials are already alarms with a measured false-alarm rate: the topic-shift detector (H36) and the three-channel change monitor (H74). For the other dials, the alarm levels in the table are proposals. They mark the edge of the range that we observed, so a crossing means that the swarm has left the regime in which the picture was measured. None of these levels has been tested as an alarm.
