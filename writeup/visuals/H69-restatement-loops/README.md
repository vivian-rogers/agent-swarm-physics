# H69: restatement loops copy the context

`fig.pdf`/`fig.png` (double column): (a) a schematic of the copy test (colored blocks stand for an agent's own statements; no text); (b) per-period in-context enrichment (Mantel–Haenszel OR of a near-copy for a source still in the current context segment vs one erased, stratified by agent × log-lag × calls-between; agent-day bootstrap CIs) with the pseudo-erasure OR (fake boundary at the segment midpoint) as the gray null and the random-effects pool over the four scorable periods (G38, G40, G41, G51; others faded); (c) loop-exit ORs for a forced erasure between two statements per scorable period (Wald, agent-day clusters) with the pooled exit and onset ORs. `anim.mp4` (14.0 s, 1280×720) is a schematic: colored blocks stand for one agent's statements; each new statement copies an in-context one with odds that grow with the number of own statements in the segment, a loop builds, and a forced wipe empties the context so the next segment starts fresh. Its rates are illustrative, not fitted; the burned-in note quotes the measured 3.4× enrichment and 2.4× exit.
