# H51: one dial fails

`fig.pdf` (double column) reads H51's `results/phase_points.parquet` (per period: `N_active`, `K` = H67's pooled g_lag with `g_lag_se`, and the unfitted observables `Y1_settle` = ln τ_settle, `Y2_herd` = herding share, `Y3_branch` = logit R̂, `Y4_loop` = logit loop rate) and the primary leave-one-period-out CV-R² from `results/collapse.json`. Panel (a) is the card's proposed phase diagram (x = N log, y = g_lag, marker = regime). Panel (b) shows small multiples of each observable against g_lag and against N, with the CV-R² of the single-variable dial in each axis label. These match the card's Headline (g_lag: −0.00, 0.03, −0.01, 0.22; log N herding 0.38). The gray band is an illustration of the card's mean-field bound, not a fitted null. Starting from the median of periods with |g_lag| < 0.05, it shows ± ln χ(g) for log or logit observables and ×χ(g)^{±1} for herding share: the most a χ = 1/(1 − g) amplification can move an observable.
