# H44 + H15: the forced context wipe

`fig.pdf`/`fig.png` (double column) shows what a forced context wipe (NE41, the 41-record cap) does to one agent: (a) a schematic of the context window filling and being wiped; (b)–(d) the G51 event study around forced wipes (vermillion, agent-day bootstrap 95% band) against no-reset pseudo-erasures at segment call 21 (gray band): write share, DQ4 work commits per call and re-acquisition share; (e) the per-period work-commit dip over calls +1…+10 vs the far reference, with the pseudo-erasure control in gray and the DerSimonian–Laird pool; (f) command-loop recurrence after a forced wipe vs a no-reset boundary (Wilson binomial intervals, periods with ≥ 30 loop events). `writeup/animations/H44-context-wipe.mp4` (16.8 s, 1280×720) fills one agent's context window block by block, with block categories sampled from the measured G51 call-category shares at each segment position, wipes it at the cap, and draws the measured G51 write-share curve as the output meter; the command loop in the second segment is schematic.

Data: `data/processed/H44-erasure-reacquisition-thrash/{G36..G51,NE41}/results.json` (curves, contrasts, loops, pooled). Numbers in the caption: H44 card, "Results" (G51 0.22 → 0.47, ℓ 5–7 calls, ℓ_W ≈ 3, work commits −38% [−41, −35], loops 16% vs 72% and pooled OR 0.11 [0.05, 0.26]); H15 card, "Round 1b" (work commits −39% [−42, −35], 7/9 periods). Build: `uv run python writeup/visuals/H44-context-wipe/make.py` (`--no-anim` for the figure only).
