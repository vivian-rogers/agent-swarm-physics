# H18 visual: attention dilution

`fig.pdf`/`fig.png` (double column, no animation). Panel (a) shows the binned response curves (observed / expected under the no-budget model with agent×day propensities) vs ledger k for all 16 periods, with the no-budget null and the literal 1/k guide. Panel (b) is the honest "beyond which null" panel: the per-period exponent on all talk calls (D1) and on timer-wake batches (D2), against the generative-agent reactive-timing null. Panel (c) is the G51 reply-parent rate by queue rank (recency).

Data: `data/processed/H18-attention-dilution/r1b/` (`G<NN>/fits_mention.json` curves; `summary_r1b.json` per-period β, D2 and `pooled_mention`; `G51/talks.parquet` and `G51/pending.parquet` for (c), codes only, recomputed here with a day bootstrap, B = 200) and `synthetic/B.parquet` (scenario `react_const`, variant `main`). Numbers are from the card's Round 1b table and the P1/P5 rows: 16/16, pooled 0.66 ± 0.02; G51 D2 0.45 [0.41, 0.50]; G38 D2 −0.02. The synthetic reactive-timing null is 0.78 ± 0.02 in the card's table; this figure shows the 8-replicate range 0.75–0.80. Panel (a) draws no fitted k^−0.66 line: the binned obs/exp curves are shallower than the hazard-model exponent, so the fit is shown as numbers in (b). Build: `uv run python writeup/visuals/H18-attention-dilution/make.py`.
