# H96 visual: a goal switch is a quench

`make.py` builds `fig.pdf`/`fig.png` (double column, static; the motion of the same kind of switch is H97's animation (`writeup/animations/H97-quench-restoring-force.mp4`)). Panel (a) is an illustration in the shared content plane (`writeup/visuals/_quench_common.py`, H97 design `T39`, bge white32), not H96's estimator: the swarm-mean old-state coordinate is ×1.06 across the last ordinary night of #38 and ×0.11 across the kickoff. Panels (b, c) use H96's own outputs: `data/processed/H96-goal-switch-hysteresis/results/transitions_{bge_small,gte_modernbert}_style_resid32.json` (`M_series` over the active-hour bins of `h96lib.BINS`, `R1` with CIs) and `results/card.json` (pseudo-switch reference by regime, random-effects ΔR₁). Caption numbers are from the card Status and "Outcome vs prediction" (P1). Non-holdout only; no text is read.
