# H47 visual: room coherence length

`fig.pdf`/`fig.png` (double column, static; no animation). (a) is a small simulation (two rooms of 5 and 10 agents; room-specific drives vs one shared drive) showing what C_B measures: the global share of a room's content fluctuation (card Amendment 1a). (b) plots C_B per period with its day-bootstrap CI against the median between-room topic separation F, with the room-relabel null medians as the gray band and the C_B ≤ 0.3 rule line; numbers from `data/processed/H47-room-coherence-length/results/summary.json`, `coherence.json` and `separation.json` (card "Results by goal period", "Headline" 1 and 4; the F axis is post hoc). (c) shows NE42's A-B-A r_X with the partition-permutation null medians and the DiD from `results/ne42.json` (card NE42 row, Headline 2). H47 uses bge only (no gte swap yet). Nothing is recomputed from statements; the shared room pipeline (`../_rooms_common.py`) is not needed here. Build: `uv run python writeup/visuals/H47-room-coherence-length/make.py`.
