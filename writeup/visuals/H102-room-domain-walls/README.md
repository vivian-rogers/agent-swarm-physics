# H102 visual: domains without a wall

`fig.pdf`/`fig.png` (double column): (a) schematic of the domain-wall picture (model: hoppers inside the wall; observed: content follows the room of the statement); (b) bimodality D per unit vs the relabel-null 95th percentile; (c) #51g wall-coordinate distribution of statements (stayers in #general, residents in #focus) with the stayers' leave-one-out rug and the three #general hoppers that spoke in #focus; (d) hopper-day s(home) vs ln(1 + R_hop) with H102's κ_R and the powered κ = 0.1 alternative. D, the rug, hopper positions and κ_R are read from `data/processed/H102-room-domain-walls/results/raw_bge_small_style_resid.json` (card "Results by goal period", "Headline" 1–4, P2, P3); the statement densities and the animation use `../_rooms_common.py` (shared bge style-residualized statement vectors, `rooms_asof`, day-centred) restricted to H102's 51g statement set, with H102's axis rule (full-data core-stayer centroids, s = 0 #general, 1 #focus). That pipeline reproduces H102's hopper values exactly (Fable 5 s(#general) 0.060, s(#focus) 0.154; Gemini 3.5 Flash 0.088 / 0.511; GLM-5.2 0.005 / 0.256). `anim.mp4` (21.5 s, 1280×720, 24 fps; `anim_poster.png` = last day) runs over 08-05 → 08-21 on a compressed active clock: each token is a hopper's running mean (last 15 statements within its current room stay) over the two statement-density hills, and the rows below show every statement (jittered), pink outlined for those said in #focus, with running means by room. No message text is shown. Build: `uv run python writeup/visuals/H102-room-domain-walls/make.py [--static] [--anim]`.
