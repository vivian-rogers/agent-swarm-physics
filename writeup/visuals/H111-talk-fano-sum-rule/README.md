# H111: talk Fano sum rule

`fig.pdf` (double column). Panel (a) is a simulation: a discrete-time linear Hawkes swarm with branching ratio g. Φ(10 min) is computed with the card's estimator (60-min block demeaning) and plotted against the card's room-adjusted Φ_pred(g) and the bare 1/(1 − g)². Panel (b) is the measured quantity: per-unit Φ(10 min) with its hour-block bootstrap CI (`results/units.parquet: phi_10, phi_10_lo/hi`) against Φ_pred (`phi_pred`, from H67's g_lag). The horizontal error bars propagate H67's `g_se` through the card's formula (delta method, 95%). Units are those with ≥ 40 usable 10-min windows (`nwin_10`; 41 units: regime I 21, II 2, III 18), as in the card. The pooled ratios come from `results/summary.json` (`r_F_pooled_III` 1.01 [0.94, 1.09], `r_F_pooled_I` 1.34 [1.18, 1.52]) and match the card's Headline and "Claim that stands". The gray band in (b) is the median over units of the block-shift null's 95th percentile (`phi_null_q95`, 1.33), drawn as a single level. The ±20% band is the card's P1 tolerance. The card and data were uncommitted round-1 work when this was built. No animation. Build: `uv run python writeup/visuals/H111-talk-fano-sum-rule/make.py`.
