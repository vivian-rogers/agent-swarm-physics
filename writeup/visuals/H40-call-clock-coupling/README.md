# H40 visual: the call clock

`fig.pdf`/`fig.png` (double column, no animation: the still carries it). Panel (a) is an analytic illustration of the call clock (same hazard per call: curves collapse in calls and smear in minutes). Panel (b) is η per period with regime random-effects means, against the call-clock (0) and wall-clock (1) references. Panels (c) and (d) are G51's per-agent couplings vs call rate: per call (flat) and per hour (slope ≈ 1), with the wall-clock rival dashed.

Data: `data/processed/H40-call-clock-coupling/results/` (`replication_table.parquet`, `summary.json` → `RE_eta`, `G51.json` → `au_table` and `between`). Points in (c) and (d) use H40's own selection (≥ 5 replies; asserted to give the card's 243 agent-units) and are centred within unit with the meta-regression weights 1/(se² + τ²). Numbers are from the card's Status and Outcome-vs-prediction rows: η by regime +0.51 / −0.01 / −0.16; G51 s +0.11 [−0.03, +0.25]; per-hour slope (model-free) 1.00 [0.81, 1.19]. The model-based 1 + s = 1.11 drawn in (d) is labelled as such. G38 (−0.57) and G44 (−0.34) are below zero, the card's open redirect R6. The card's P5 collapse test (cadence tertiles) failed marginally (21/33), so the collapse in (a) is a model illustration, not a data claim. Build: `uv run python writeup/visuals/H40-call-clock-coupling/make.py`.
