# H88 visual: collective memory decay

`make.py` builds `fig.pdf`/`fig.png` (double column, static). Inputs: `data/processed/H88-collective-memory-decay/daily.parquet` (veteran and newcomer term uses y and offsets O per village day; observed, non-holdout days only, asserted by `h88lib.load_daily`), `replication/replication.json` (per-period M1c/M2 fits, card medians τ 5.5, floor 0.019, τ₁ 2.0, τ₂ 48, best-model counts, newcomer R and b) and `synthetic/synthetic.json` (slow-only newcomer b). Panel (a) normalizes each period by its own M1c fit at k = 1 (a display choice; fits are per period, never pooled); the biexponential's amplitude ratio is the median over the four periods where it won. Panel (b) recomputes the card's indirectly standardized ratios with `h88lib._band_table` (they equal the card's 0.93 / 0.64 / 0.79) and adds per-band period-bootstrap CIs. Caption numbers are from the card Status, "Outcome vs prediction" (P1, P3) and Results. No text is read.
