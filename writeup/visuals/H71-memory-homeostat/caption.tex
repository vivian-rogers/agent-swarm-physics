\caption{Memory size is held by a homeostat on the consolidation clock.
(a) Memory size of two G51 agents over 90 minutes: append snapshots grow the memory file and each consolidation compresses it (triangles) back toward the agent's set point (dashed: its mean post-compression size in G51).
(b) G51 post-compression deviation from the agent set point against the previous cycle's deviation (26{,}681 cycles, 15 quantile bins, agent-bootstrap 95\% intervals). The fitted persistence $\phi^+ = 0.81$ $[0.75, 0.88]$ (green) lies between a random walk (slope 1, gray null) and a deadbeat reset (slope 0); the next cycle does not overshoot to the other side.
(c) $\phi^+$ in all 37 non-holdout period units: the interval excludes 1 in 37/37, pooled 0.67 $[0.63, 0.71]$. Forced and voluntary consolidations give the same $\phi^+$ ($|F-V|<0.15$ in 9/10 regime-III periods). The loop is not first order (AR(2) median $+0.19$): a fast compression tracks a set point that drifts slowly (persistence $\approx 0.82$ per cycle).}
