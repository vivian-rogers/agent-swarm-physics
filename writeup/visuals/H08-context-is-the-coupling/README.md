# H08 visual: context is the coupling

`fig.pdf`/`fig.png` (double column) shows that a message changes a recipient only at the first model call that has it in context. Panel (a) is one real G38 message (2026-04-02) drawn on the ledger's call windows: room-mates already mid-call cannot respond; each reads it at its next call, and the replies come from that call. Panel (b) is G38's turn-offset profile for naming the sender, net of the pseudo-message null, with the other-room placebo as the gray null curve. Panel (c) is the jump $D=G(1)-G(0)$ per period (reply author, mention, other-room placebo). `writeup/animations/H08-context-is-the-coupling.mp4` (18 s, 1280×720, not committed) plays panel (a) in time: the post glows, the message waits unread on each lane, the receiving call flashes, and reply arrows go back to the sender. `H08-context-is-the-coupling_poster.png` is its last full frame.

Data: `data/processed/H08-context-is-the-coupling/r1b/` (`G<NN>/c9.json` for every period, `G38/readout.parquet` and `G38/turns.parquet` for the example), the shared `chat_core` (message time and room, no text) and `roster` (names). The example day is checked against the holdout. Numbers come from the card's "Round 1b" C9 table (G38: D_addr +1.14 [+0.80, +1.41], D reply author +1.69 [+1.39, +1.95]; addressing 14/17, reply author 17/17; other-room placebo 8/8 with |D| ≤ 0.15 pp). Build: `uv run python writeup/visuals/H08-context-is-the-coupling/make.py [--no-anim]`.
