# H85: output scaling with N

`fig.pdf` (double column) reads H85's `units.parquet` (replication filter T_h ≥ 1 h, msg ≥ 20: 71 units, 35 goal clusters) and, for per-unit call counts, H86's `bins15.parquet` (as in H85's post hoc PH2). Panel (a) refits model M1 with H85's own `h85lib.design`/`ols` and the same goal-cluster bootstrap (B = 2000, seed 20261004). It reproduces the card's β_msg = 0.33 [−0.18, 0.64] exactly. The regime lines carry the bootstrap 95% band, and the dashed lines have slope 1 through each regime's centroid. Panel (b) splits the regime-I exponent of room messages per hour into ln N + ln(calls / agent-hour) + ln(talk share of calls) + ln(messages per talk call). OLS slopes add exactly: 1 − 0.02 − 0.89 + 0.00 = 0.09, matching the card's Results §1 and PH2 within-I values. The component CIs are this script's own goal-cluster bootstrap within regime I. The total's CI [−0.31, 0.53] is the card's (`replication.json`, `within_I`). No animation. Build: `uv run python writeup/visuals/H85-output-scaling-with-n/make.py`.
