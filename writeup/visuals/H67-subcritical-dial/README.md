# H67 + H25: the subcritical dial

The static figure (`fig.pdf`, double column) puts every non-holdout goal period on the Curie–Weiss amplification curve χ = 1/(1 − g) at its read-out loop gain g_lag (H67 `results/periods.parquet`, random-effects pool, 95% CI). It also shows H25's daily equal-time dial (round 1b `r1b/dial_daily.parquet`, variant `auto`, 282 days per channel) as strips. Panel (b) is g_lag per period in time order. Its gray bars are the per-period median of the units' shift-null 95th percentile (`units.parquet: shift_g_q95`); the orange diamonds are the equal-time dial on the same calls (`g_eq`). Card numbers used: regime-III unit median 0.13, every unit's upper bound < 0.40 (H67 Status and Headline); max period g_lag 0.234 → χ ≤ 1.31 (H51 Status); H25 round-1b medians 0.159 / 0.162 and max daily upper bounds 0.77 / 0.68 (H25 Round 1b table). The animation (`writeup/animations/H67-subcritical-dial.mp4`, 20 s, simulation only) runs three branching talk swarms (24 agents) under the same Poisson pushes, with g = 0.13 (village), 0.6 and 0.95. A live counter shows talk events per push converging to χ (1.15, 2.5, 20). Simulated time is circular, so the movie loops exactly. Build: `uv run python writeup/visuals/H67-subcritical-dial/make.py [--fig|--anim]`.
