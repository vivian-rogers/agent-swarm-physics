\caption{The $\kappa$ table: only the context window buys commits per bit.
Each row is a channel scored at its natural scramble (NE41 forced erasures, 18{,}760 events vs 19{,}886 pseudo-erasures; the kickoff at new-goal nights, NE34).
(a) Allocation information $I_c$ (bits about the repo of the next commit, beyond agent identity; the within-agent permutation floor is subtracted). Rows whose lower bound is under 0.02 bits (gray) are not identified.
(b) Value $\Delta V_c$ in work commits per 20 calls: erasing the context costs 0.41 $[0.36, 0.45]$ (41\% of output); every other row's interval includes 0. Receiving any chat item after an erasure (hollow) adds output without repo bits.
(c) $\kappa_c=\Delta V_c/I_c$ where both rows are identified: $\kappa_C = 5.2$ $[3.8, 7.9]$, $\kappa_A = -0.6$ $[-1.6, +0.3]$, $P(\kappa_C>\kappa_A)=1.00$; ``n.i.'' = not identified.
(d) The artifact tells the agent where to work: 89\% of first commits after a forced erasure land in its own repo (87\% after a pseudo-erasure), and re-reading the artifact raises that to 96\% in both arms, so it adds no output beyond its placebo association. Bars: agent-day paired bootstrap 95\% intervals (a--c), binomial intervals (d).}
