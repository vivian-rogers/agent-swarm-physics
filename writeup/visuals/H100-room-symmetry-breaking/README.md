# H100 visual: rooms break the symmetry anew at each goal

`fig.pdf`/`fig.png` (double column): (a) a two-block soft-spin simulation of explicit vs spontaneous symmetry breaking; (b) Q and Q_spont per period with the room-relabel null (95th percentile from the null mean and sd); (c) composition / field-direction / spontaneous shares per regime-III period; (d) remanence R between consecutive periods against the joint-relabel null. Panels (b)–(d) read `data/processed/H100-room-symmetry-breaking/results/raw_bge_small_style_resid.json` (card "Results by goal period", "Headline" 1–4, P4, P6). `anim.mp4` (22.2 s, 1280×720, 24 fps; `anim_poster.png` = last #41 frame) follows #39 → #40 (NE42 merge) → #41: agents are points in the 2-D content plane spanned by the #39 and #41 room differences, built by `../_rooms_common.py` (shared bge style-residualized statement vectors, rooms from `infra/shared/rooms_asof.py`, day-centred), minus H100's leave-period-out agent constants (periods #39 and #41 left out) and its field directions; positions are a within-period exponential average over days (τ = 1.5 days). The in-plane angle reproduces the card's R(#39, #41) = −0.13. The dial tracks the split direction; the strip shows the daily split size |Δ(d)|² (fixed #39/#41 partition, also in the merged week) against a joint-relabel null (2,000 draws, 5–95%). The plane is defined in-sample by the observed room differences, so the separation along it is inflated; the cross-fitted statistics and nulls are in the static figure. Build: `uv run python writeup/visuals/H100-room-symmetry-breaking/make.py [--static] [--anim]`.
