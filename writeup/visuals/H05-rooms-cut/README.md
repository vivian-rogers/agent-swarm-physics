# H05 visual: rooms cut chat only through reads

`fig.pdf`/`fig.png` (double column, static; no animation: the result is a set of coefficients, not a motion). Panel (a) is a schematic of the two-block kinetic Ising model (rooms as coupled blocks, the cut removes cross-room reads). Panel (b) shows the within-minus-cross excess lagged coupling κ_x per regime-III two-room window for talk and activity spins against the room-label null (±1.96 null sd), read from `data/processed/H05-rooms-cut/r1b/explore_bin1.json` (X2, X2_pooled_III; card "Round 1b", table "Old vs new"). Panel (c) is a forest plot of effects on talk κ_x: the 05-11 split pair DiD (X3 `split_0511`, card "Old vs new": −0.020, p 0.027) with an assignment-permutation null redrawn here from `r1b/pair_day_bin1.parquet` by H05's rule (2,000 draws; the band only, the p-value shown is H05's), and the HH248 regressions from `r1b/r1b_reads.json` (card "New tests": 0.0123 z 5.1 → 0.0013 z 0.2; reads z 2.1; activity z −0.05). NE12 itself separated no pair and NE15's pre side is held out, so the before/after-cut panel uses the non-holdout NE42 split; the holdout NE15 C1 numbers appear only in the caption, as quoted in the card's confirmatory table.
