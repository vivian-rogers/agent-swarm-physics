# H108 visual: room direction persists

`fig.pdf`/`fig.png` (double column, static; no animation). (a) simulates the angle of a room order parameter: free angular diffusion at the pooled identical-kickoff D_θ vs an Ornstein–Uhlenbeck angle pinned by a field at the pooled fielded D_θ (illustrative). (b) plots the measured P(ℓ) curves per period (lags with ≥ 2 day pairs) with the pooled exponential decays; (c) plots P(1) per period with agent-bootstrap CIs against the regenerating synthetic world's 10–90% band and the pooled group values. All numbers are read from `data/processed/H108-goldstone-room-wandering/results/raw_all.json` (bge style_resid with constants; card "Results by goal period", "Headline" 1–5, "Claim that stands") and `synthetic/synthetic_summary.json` (regen_c0.0_rho1.0; card Amendment 1). The agent-bootstrap CIs sit below the point estimate in #39 (a known issue: duplicated agents shift the relabel null); the plot draws them as given.
