# H81 visual: the regime-I collective slow mode

`make.py` builds `fig.pdf`/`fig.png` (double column; static only, no animation: a 2-D projection of the 32-d block culture vectors would carry little of the variance and could suggest more smoothness than the data show). Inputs: `data/processed/H81-culture-beyond-composition/` — `replication/pairs_{bge_small,gte_modernbert}_I.parquet` (real block-pair similarities; the profile is checked against `replication.json`), `blocks.parquet` (block membership for panel a), `replication/replication.json` (primary and size-matched contrasts with their S0 95th percentiles; OU fit τ), `round2/r2_results.json` (D_adjg after operator-direction removal). The S0 band per lag bin in (b, c) is recomputed with the card's own synthetic (`h81lib.simulate` with share = 0, the A1 two-way FE estimator, real regime-I panel, 200 replicates per model, about one minute at 2 threads), since the stored replicates keep only summary contrasts. The top strip of (a) is a labelled simulation. Caption numbers are from the card's Status, "Outcome vs prediction" (P2, P3, P5) and round-2 table (R2a) and Claim that stands. Non-holdout only (the H81 scheme drops held-out rows); no text is read.
